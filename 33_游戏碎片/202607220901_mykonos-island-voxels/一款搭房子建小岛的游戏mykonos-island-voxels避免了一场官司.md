酒过三巡，菜过五味，老邹忽然撂下筷子，跟我聊起了前几年的一桩怪事。

我一时来了兴趣，也放下筷子，递了一根华子过去。



这个老邹是我的发小，小时候到一块就打架，现在关系铁得很。

老邹从小学习好，自从他年轻的时候进了家大公司，我们都觉得他前途无量，从此过上了好日子。

可没想到打那之后，他总和我吐槽，说公司里总有人排挤他。

什么拉帮结派、勾心斗角的，老邹为人本分老实，脏活苦活累活就基本成了他一个人的事。

有一回，他辛辛苦苦通宵了几个晚上，好不容易自己负责的项目大获成功，结果奖却颁给了别人。

自此后老邹是天天借酒浇愁，说什么也不干了，嚷着要辞职。

老邹眯缝着眼睛盯着电脑就琢磨，这一琢磨就过去了1个小时外加60分钟。

最后他把辞职信塞进背包里，人直接拐到领导办公室。

老邹当即表示有心理准备，都想好了，家里也没问题！

事后他找我喝酒，一口干下跟我说：“放心，现在爹妈身体还行，孩子也挺懂事，与其在公司里受窝囊气，不如去外边看看，反正到哪都是干活，凭本事吃饭呗！”

他正怀疑是不是走错了道，这时前面冒出来一座茶摊。

老邹把行李往旁边一放，刚一屁股坐在了凳子上，就见茶摊老板“啪”的往桌子放了一碗热茶汤。

“哦……谢谢……多少钱？”

“那就没错了，老板吩咐过，要是看见一位戴眼镜，穿蓝色格子衫、带行李，从A市来的客人，就让我们直接上菜，肯定不带错的哈！”

正巧说话这空老板从外面进来了，一手拎着几斤牛肉，一手还拎着一只鸡。

小二见老板来了，忙将老板拉到老邹近前。

老板解释，说是先前有一位叫邹正平的客人已经买过单了，吩咐说是尽最大可能关照好后面来的客人，好酒好菜尽管上。

老邹百思不得其解，就这样糊里巴涂的，终于有一天，他来到了一个叫李家洼的地方。

这个地方有好几片山林，据说住着一百多户人家。

老邹向当地人打听道时，听闻此地有两家大户，一家姓王，一家姓李，分别管着东西两片山林。

老邹一见这架势就想往路边躲躲，可没想到让人群中的一个老头看见。

那个老头一个箭步上前，冲着老邹就作揖：“请问阁下是邹正平邹先生吗？在下王府管家，这厢有礼了！”

老邹左右看看，没别人啊，指着自己的鼻子，张了张嘴，没敢说话。

老头笑了笑，往旁边一闪身，手指着山上不远处一座庄园说道：“我主人让我在此恭候多时，还请先生屈尊大驾，请到府上一叙！”

话音刚落，不等老邹反应，上来三五个仆人不由分说，七手八脚就把老邹连人带行李给架到车上。

老邹仰头长叹一声，这指定是遇上劫匪了，还不如当初辞职算了，完了，干脆把眼一闭……



待老邹再把眼睁开，好家伙，这是到了什么地方？

这分明是座豪宅啊，花红柳绿、小桥流水，老邹看得是眼花缭乱。

他也没想到这偏僻山林里居然还有这等去处！

穿过连廊，进了厅堂，酒宴早已摆下，老邹心里跟开了锅似的，这劫匪玩的是什么花活？

就见厅堂上垂首坐着一位老者，身着团花锦袍，一看就是位员外爷。

在这位旁边还坐着一位老者，同样身着锦绣，一团锐气，应该也是位员外爷。

一开始老邹有点磨不开，上垂首那位老者拱手介绍后，老邹这才明白，原来他就是当地王家大户，名叫王万里，另一位便是李家大户的员外李富贵。

王员外遂将其中原委一一道出，原来李家洼的这两家大户王家和李家本来世代友好，两家祖上几辈都是关系融洽，一向和睦相处，从来都没有红过脸、打过架。

什么事呢？

本来相安无事，可就在两个星期之前，从两家的地里长出一株葫芦藤，可巧长得不是地方，正好是在两家边界的附近。

起初也没人当回事，这葫芦藤就慢慢长出了几个葫芦，最后有人一数，不多不少拢共七个。

两家人都觉得这也没啥，可事情偏偏又起了变化。

也不知道怎么搞的，一根藤上七个葫芦的消息不胫而走，陆陆续续就有外地的游客纷纷来打卡拍照，还有不少搞cosplay的发骚友，尽是些藤精树怪、蝎子毒蛇啥的，弄得好不热闹。

好么，这下两家人再也坐不住了，都来争这葫芦藤的归属问题。

王家说是自己家的，李家说不是你们家的，各执一词，争执不下。

最后有人提醒两家，当初老祖宗为了避免不必要的争端，专门在两家边界之处立了界碑。

可是这界碑年代久远，早已不知道被埋在了哪个土里，两家都不愿意找出来，就怕丢了葫芦藤的拥有权。

谁家要是连夜将界碑挖出，对方就会说你偷偷挪动界碑做了手脚。

王员外连忙解释，说是前几日去道观里拜神上香，曾有位老道长提醒，说不日便会有一位能掐会算、颇有神通的邹姓先生路过贵庄，名曰邹正平，务必将其挽留，可解困也。

接着老邹就开始介绍了。

这个游戏只用到了纯 `HTML/CSS/ES` 模块，不需要安装，直接就能用。

不过因为浏览器会拒绝加载来自 `file://` 开头的 `ES` 模块，所以我们就需要通过 `HTTP` 服务来启动它。

`file://` 开头是啥意思呢？

就是把文件当成本地去运行 `Web` 页面，那样是不行的，所以还是要老老实实搭建个 `Web` 引擎，然后通过 `http` 访问网站式的方式来打开它。

比如，我搭建了一个 `Web` 网站，然后放到了 `mykonos-island-voxels` 目录，于是我就可以这样运行。

```
http://localhost/mykonos-island-voxels
```

图03



运行 `Web` 引擎，最简单可以使用 `Caddy` 程序（单文件，文末打包下载），像下面以命令行方式运行。

```
caddy_windows_amd64.exe file-server
```



不会输入命令行的话，可以直接运行批处理文件，双击即可。

`Web` 引擎启动后，它就在后台运行了，这时就可以直接打开浏览器访问游戏了。

整个游戏的文件结构如下，想要动手修改可以按这个来。

```
.

│   ├── config.js            # 配置脚本，网格大小、磁贴调光、调色板、调试标志
│   ├── core/
│   │   ├── Game.js          # 游戏状态 + 工具调度
│   │   ├── Camera.js        # 平移/缩放/更改通知
│   │   ├── Renderer.js      # 分层画布缓存 + 动画
│   │   └── InputManager.js  # 鼠标 + 触摸 + 键盘
│   ├── grid/
│   │   ├── IsoGrid.js       # 屏幕 ↔ 单元计算
│   │   └── TileMap.js       # 地形 + 物体,占用指数
│   ├── building/
```

游戏里的场地大小是写在配置文件中的，默认是 `14 x 14` 。

在游戏里面没办法直接扩大地图的尺寸，不过通过修改配置文件源码实现。

把其中的 `width` 和 `height` 改大，比如 20 x 20、24 x 24，就可以了。

但是请注意哈，地图越大，首次加载和渲染会更慢。

搭建好的小岛是可以保存的，可以通过按下 `S` 键手动保存，也可以通过左侧工具栏当中的 `Save` 保存。

下次重新打开同一个地址时，会自动读取上次存档，存档存在浏览器的 `localStorage` 里，并不在服务器中。

也就是说，你正常关掉标签页、关掉浏览器，然后再回来，一般还在。

但前提是还是用的这个浏览器、这个地址访问地址。

如果清除了浏览器站点数据，或使用无痕模式，或更换了网址端口，或干脆换了浏览器，那么可能就真的没了。
