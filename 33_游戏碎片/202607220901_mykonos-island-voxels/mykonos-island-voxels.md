酒过三巡，菜过五味，老李放下筷子就跟我说起了前几年的一桩怪事。

我一听来了兴趣，也放下筷子，递了一根烟过去。



这位老李是我的发小，小时候经常打架，关系却铁得很。

自从年轻的时候他进了单位，我们都认为他从此过上好日子了。

没想到后来他经常和我吐槽，说老是被单位里其他人排挤。

单位里拉帮结派、勾心斗角，老李为人老实，脏活苦活累活就基本成了他一个人的事。

有一回好不容易他负责的项目大获成功，结果获奖的是别人。

自此他天天借酒浇愁，说什么也不干了，要辞职。

辞职信改了几个版本，最后写好了天天揣兜里。



就在他下定决心交辞职信的那一天，单位里发了个通知，说是市里要选人去西部支援开发，他们单位里就有一个名额。

通知其实已经发了有两三天了，但是根本没人报名。

老李眯缝着眼睛盯着电脑就琢磨，这一琢磨就琢磨了2个小时。

最后他把辞职信塞进背包里，人直接去找领导。



领导见老李主动来投，先是惊喜，后又有点皱眉。

之所以惊喜，毕竟正发愁名额任务无法完成。

之所以皱眉，怕就怕老李一时冲动，别再两天再反悔。

领导冲老李笑了笑：“小李啊，你可要想好了，这可不是闹着玩的。那地方海拔4000多米，冬天气温低得吓人，你愿意受那个罪？再说想回趟家还得好几天，这离家时间一长，家里老人孩子你都安顿好了？”

老李当即表示有心理准备，都想好了，家里也没问题！

事后他找我喝酒，一口干下跟我说：“放心，现在爹妈身体还行，孩子也挺懂事，与其在单位里受窝囊气，不如去外边看看，反正到哪都是干活，凭本事吃饭呗！”

后来我去送他，他向我保证，准能干出个人样来！



谁也没想到，就在他去的那个地方的半路上，碰见几件怪事。

他一个人拖着行李箱，走在偏僻荒凉的路上，好不容易找到一家路边的茶摊。

他刚把行李放一边，屁股还没坐在凳子上，茶摊的老板就端上一碗茶汤来。

“谢谢老板！多少钱？”

“不要钱，喝吧！有人付过钱了！”

老板的回答让老李愣了一下，他就问老板：“有人付替我付过钱？可我第一次来这儿啊？”

老板挠了挠头：“哦，对了，那人好像说他姓周，叫周正平！”

老周一口茶差点没喷出来，心想：什么？我不就叫周正平吗？难道同名同姓？天底下有这么凑巧的事？



离开茶摊，老周继续赶路，明明十几里的路愣是大半天才走了一半。

远远望去，好像到了一个镇上，有家饭店挂着开着门。

此时老周饥肠辘辘，没多想就走进这家饭店。

这店里倒是有三两个客人，各自吃着。

老周找了个靠窗户的地方刚坐下，服务员就热情地在桌上摆了三个菜一个汤。

“哎，等等……等等，是不是弄错了？这不是我点的菜吧？”

服务员微笑着对老周说：“没错，老板吩咐过了，要是看见一位戴眼镜，穿蓝色上衣、带行李的客人，让我们直接上菜，肯定没错哈！”

“不是不是，你等等……你们老板怎么知道的？”

这时正巧老板从外面进来，一只手拎着几斤牛肉，另一只手还拎着一只鸡。

服务员见老板来了，忙将老板拉到老周近前。

老板解释，说是有一位叫周正平的人已经买过单了，说是尽量照顾好来的客人，有什么菜尽管上。

老周一头雾水，心里纳闷，这偏远地区也没有什么亲戚朋友，怎么会有人请客吃饭呢？



就这样一路之上，老周的吃喝住宿基本都有人替他付了钱。

老周则是百思不得其解。



终于有一天，他来到一个叫李家洼的地方。

这个地方有好几座大山，住着一百多户人家。

老周向当地人打听，说是此地有两家大户，一家姓王，一家姓李，分别管着两片山区。

似乎这个地方正属自己要去报道的单位管辖。

老周加紧脚步，想在天黑之前赶到单位报道。

可没想到他刚走进村口，对面迎着来了一伙人。

只见这伙人吹吹打打，各个喜气洋洋。

老周见这阵势就想躲在一边，却没想到让其中一位领头的老者看见。

这位老者一个箭步上前，冲着老周作揖。

“请问阁下是周正平周先生吗？老朽王万里，这厢有礼了！”

老周左右看看，没别人啊，指着自己的鼻子，张了张嘴。

老者笑了笑，往旁边一闪身，手指着不远处一座庄园说道：“还请周先生屈尊大驾，请到寒舍吃一杯茶吧！”

刚说完，不等老周反应过来，底下几个仆人上来七手八脚就把老周的行李给扛的扛、拿的拿。

老周一看，这不去还不行，得，那就干脆走一趟吧……



好家伙，这分明是座豪宅嘛，老周看得眼花缭乱。

进了厅堂，酒宴早已摆下。

一开始老周有点磨不开，老者自我介绍后，老周才知道，原来这位老者就是当地王家大户，名叫王万里。

老者将其中原委一一道出，老周这才听明白。

原来这李家洼的这两家大户，王家和李家本来世代友好，两家祖上几辈都是关系融洽，一向和睦相处，从来都没有红过脸、打过架。

然而直到前两个星期，因为一桩事情弄得两家突然起了冲突，以至于现在都翻了脸。

什么事情呢？

两家世世代代都共同管理着李家洼的山林，从祖上就分了两块地，东头归王家管，西边由李家管。

本来相安无事，却在两个星期之前，从两家地的边界处长出一株葫芦藤。

起初也没人当回事，这葫芦藤就慢慢长出了几个葫芦，最后有人一数，不多不少拢共七个。

两家人觉得这也没啥，可事情偏偏却起了变化。

也不知道这消息怎么传的，陆陆续续就有外地的游客纷纷来打卡拍照，还有不少搞cosplay的发骚友，尽是些藤精树怪、蝎子毒蛇啥的。

这下两家人家再也坐不住了，都来争这葫芦藤的归属问题。

王家说是王家的，李家说是李家的，各执一词，争执不下。

最后有人提醒两家，当初老祖宗为避免不必要的争端，专门在两家边界之处立了界碑。

这个游戏只用到了纯 `HTML/CSS/ES` 模块，不需要安装啥的，直接就能用。

不过因为浏览器会拒绝加载来自 `file://` 开头的 `ES` 模块，所以我们就需要通过 `HTTP` 服务来启动它。

`file://` 开头是啥意思呢？

就是把文件当成本地去运行 `Web` 页面，那样是不行的，所以还是要老老实实搭建个 `Web` 引擎，然后通过 `http` 访问网站式的方式来打开它。

比如，我搭建了一个 `Web` 网站，然后放到了 `mykonos-island-voxels` 目录，于是我就可以这样运行。

```
http://localhost/mykonos-island-voxels
```

图a03



运行 `Web` 引擎，最简单可以使用 `Caddy` 程序（单文件，文末打包下载），像下面以命令行方式运行。

```
caddy_windows_amd64.exe file-server
```



不会输入命令行的朋友可以直接运行批处理文件，双击即可。

游戏里的场地大小是写在配置文件中的，默认是 `14 x 14` 。

在游戏里面没办法直接扩大地图的尺寸，不过通过修改配置文件源码实现。

把其中的 `width` 和 `height` 改大，比如 20 x 20、24 x 24，就可以了。

图a04



但是请注意哈，地图越大，首次加载和渲染会更慢。

图a05





搭建好的小岛是可以保存的，可以通过按下 `S` 键手动保存，也可以通过左侧工具栏当中的 `Save` 保存。

下次重新打开同一个地址时，会自动读取上次存档，存档存在浏览器的 `localStorage` 里，并不在服务器中。

也就是说，你正常关掉标签页、关掉浏览器，然后再回来，一般还在。

但前提是还是用的这个浏览器、这个地址访问地址。

如果清除了浏览器站点数据，或使用无痕模式，或更换了网址端口，或干脆换了浏览器，那么可能就真的没了。
