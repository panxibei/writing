酒过三巡，菜过五味，老邹忽然撂下筷子，跟我聊起了前几年的一桩怪事。

我一时来了兴趣，也放下筷子，递了一根华子过去。



这个老邹是我的发小，小时候到一块就打架，现在关系铁得很。

老邹从小学习好，自从他年轻的时候进了个大公司，我们都觉得他前途无量，从此过上了好日子。

可没想到在那之后，他总和我吐槽，说被公司里的人排挤。

什么拉帮结派、勾心斗角的，老邹为人本分老实，脏活苦活累活就基本成了他一个人的事。

有一回，他辛辛苦苦通宵了几个晚上，好不容易自己负责的项目大获成功，结果奖却颁给了别人。

自此后老邹是天天借酒浇愁，说什么也不干了，嚷着要辞职。

辞职信改了十几个版本，最后那一版终于定稿了，天天揣兜里带着。



就在他下定决心交辞职信的那一天，单位里发了个通知，说是偏远山区的分公司要选调人员去支援发展，职务直接升为组长，眼下就只有一个名额。

通知其实已经发了有两三天了，根本没人报名。

老邹眯缝着眼睛盯着电脑就琢磨，这一琢磨就过去了1个小时外加60分钟。

最后他把辞职信塞进背包里，人直接拐到领导办公室。



领导见老邹主动来投，先是惊喜，后又皱眉。

之所以惊喜，毕竟正发愁选调名额的事，这下终于来了个冤大头。

之所以皱眉，就怕老邹一时冲动，别过两天再反悔。

领导冲老邹笑了笑：“小李啊，你可要想好了，这可不是闹着玩的。

那地方海拔2000多米，冬天气温低得吓人，你愿意受那个罪？

再说想回趟家还得好几天，这离家时间一长，家里老人孩子你都安顿好了？”

老邹当即表示有心理准备，都想好了，家里也没问题！

事后他找我喝酒，一口干下跟我说：“放心，现在爹妈身体还行，孩子也挺懂事，与其在公司里受窝囊气，不如去外边看看，反正到哪都是干活，凭本事吃饭呗！”

后来我去送他，他向我发誓，准保能干出个人样来！

可就在他去的半路上，撞见了几件怪事……



就在第二天，老邹一个人拖着行李箱，不知不觉拐弯抹角走到了一条偏僻小路上，四周围一片荒凉。

他正怀疑是不是走错了道，这时前面冒出来一座茶摊。

老邹把行李往旁边一放，刚一屁股坐在了凳子上，就见茶摊老板“啪”的往桌子放了一碗热茶汤。

“哦……谢谢……多少钱？”

“喝吧！付过钱了！”

老板的回答让老邹愣了一下。

再仔细看看老板，冲着自己笑嘻嘻的，却并不认识。

他就问老板：“你是这儿的老板吗？可我第头一次来这儿啊？”

老板挠了挠头：“哦，你来之前刚有个人给付过茶钱了。”

“那人是谁？”，老邹呡了一口茶问道。

“呃……那人说他姓周，好像……对了……叫邹正平！”

老邹嘴里的茶差点没喷出来，心想：什么？我不就叫周正平吗？难道同名同姓？天底下还能有这么凑巧的事？



离开茶摊，老邹继续赶路，经过十多里的跋涉，赶到了一个小镇。

想找个歇脚吃饭的地界，远远望去好像有家小店开着门。

此时老邹饥肠辘辘，脚下加紧进了小店。

靠窗户老邹找了个的地方，刚坐下，小二就十分热情地在老邹面前摆了三个菜一个汤。

“哎，等等等等，是不是弄错了？这不是我点的菜吧？”

小二笑着对老邹说：“你是不是打A市来？”

“是啊，我是第一次来这……”

“那就没错了，老板吩咐过，要是看见一位戴眼镜，穿蓝色上衣、带行李，从A市来的客人，就让我们直接上菜，肯定不带错的哈！”

小二一边说一边示意后厨加菜……

“不是不是，你先等等……你们老板是怎么知道的？”

正巧说话这空老板从外面进来了，一手拎着几斤牛肉，一手还拎着一只鸡。

小二见老板来了，忙将老板拉到老邹近前。

老板解释，说是先前有一位叫周正平的客人已经买过单了，吩咐说是尽最大可能关照好后面来的客人，好酒好菜尽管上。

老邹一头雾水，心里纳闷，这偏远地区自己从来都没什么亲戚朋友，怎么会有人请我吃饭呢？

真是奇哉怪也！



就这么一路之上，老邹的吃喝住宿基本都有人替他先付了钱。

老邹百思不得其解，就这样糊里巴涂的，终于有一天，他来到一个叫李家洼的地方。

这个地方有好几座大山，据说住着一百多户人家。

老邹向当地人打听道时，听闻此地有两家大户，一家姓王，一家姓李，分别管着东西两片山林。

老邹寻思着脚步加紧，想在天黑之前找个住处，可没想到他刚进村口没多久，对面迎着来了一伙人。

只见这伙人吹吹打打，各个脸上喜气洋洋。

老邹一见这架势就想往路边躲躲，可没想到让人群中的一位老者看见。

那位老者一个箭步上前，冲着老邹就作揖：“请问阁下是周正平周先生吗？在下王府管家，这厢有礼了！”

老邹左右看看，没别人啊，指着自己的鼻子，张了张嘴，没敢说话。

老者笑了笑，往旁边一闪身，手指着山上不远处一座庄园说道：“还请周先生屈尊大驾，请到府上一叙！”

话音刚落，不等老邹反应，底下三五个仆人不由分说，上来七手八脚就把老邹连人带行李给架到车上。

老邹仰头长叹一声，这指定是遇上当地的劫匪了，完了，干脆把眼一闭……



待老邹再把眼睁开，好家伙，这是什么地方？

这分明是座豪宅啊，花红柳绿、小桥流水，老邹看得是眼花缭乱。

他也没想到这偏僻山林居然还有这等去处！

穿过连廊，进了厅堂，酒宴早已摆下，老邹心里开了锅似的，这劫匪玩的是什么花活？

一开始老邹有点磨不开，老者自我介绍后，老邹才知道，原来这位老者就是当地王家大户，名叫王万里。

老者将其中原委一一道出，老邹这才听明白。

原来这李家洼的这两家大户，王家和李家本来世代友好，两家祖上几辈都是关系融洽，一向和睦相处，从来都没有红过脸、打过架。

然而直到前两个星期，因为一桩事情弄得两家突然起了冲突，以至于现在都翻了脸。

什么事情呢？

两家世世代代都共同管理着李家洼的山林，从祖上就分了两块地，东头归王家管，西边由李家管。

本来相安无事，可在两个星期之前，从两家地的边界处长出一株葫芦藤。

起初也没人当回事，这葫芦藤就慢慢长出了几个葫芦，最后有人一数，不多不少拢共七个。

两家人觉得这也没啥，可事情偏偏却又起了变化。

也不知道这消息怎么传出去的，陆陆续续就有外地的游客纷纷来打卡拍照，还有不少搞cosplay的发骚友，尽是些藤精树怪、蝎子毒蛇啥的。

这下两家人家再也坐不住了，都来争这葫芦藤的归属问题。

王家说是王家的，李家说是李家的，各执一词，争执不下。

最后有人提醒两家，当初老祖宗为避免不必要的争端，专门在两家边界之处立了界碑。

可是这界碑年代久远，早已被埋在了土里，两家都不愿意找出来，就怕丢了葫芦藤的拥有权。

谁家要是连夜将界碑挖出，对方就会说你偷偷挪动界碑做了手脚。

也不敢打官司，两家地契写的模糊，再加上早年祖上是口头约定为主，现在各执一词，官司难断。



事情倒是听明白了，可这和老邹又有什么关系呢？

王老汉连忙解释，说是前几天到了拜神上香的日子，去庙里时有位师傅提醒我，说是不久几日，会有一位周姓师傅路过此地，可求他解决。

这个游戏只用到了纯 `HTML/CSS/ES` 模块，不需要安装啥的，直接就能用。

不过因为浏览器会拒绝加载来自 `file://` 开头的 `ES` 模块，所以我们就需要通过 `HTTP` 服务来启动它。

`file://` 开头是啥意思呢？

就是把文件当成本地去运行 `Web` 页面，那样是不行的，所以还是要老老实实搭建个 `Web` 引擎，然后通过 `http` 访问网站式的方式来打开它。

比如，我搭建了一个 `Web` 网站，然后放到了 `mykonos-island-voxels` 目录，于是我就可以这样运行。

```
http://localhost/mykonos-island-voxels
```

图a03



运行 `Web` 引擎，最简单可以使用 `Caddy` 程序（单文件，文末打包下载），像下面以命令行方式运行。

```
caddy_windows_amd64.exe file-server
```



不会输入命令行的朋友可以直接运行批处理文件，双击即可。

整个游戏的文件结构，想要动手修改可以按这个来。

│   ├── core/

│   │   └── InputManager.js  # 鼠标 + 触摸 + 键盘
│   ├── grid/

│   │   └── TileMap.js       # 地形 + 物体,占用指数

游戏里的场地大小是写在配置文件中的，默认是 `14 x 14` 。

在游戏里面没办法直接扩大地图的尺寸，不过通过修改配置文件源码实现。

把其中的 `width` 和 `height` 改大，比如 20 x 20、24 x 24，就可以了。

但是请注意哈，地图越大，首次加载和渲染会更慢。

图a05





搭建好的小岛是可以保存的，可以通过按下 `S` 键手动保存，也可以通过左侧工具栏当中的 `Save` 保存。

下次重新打开同一个地址时，会自动读取上次存档，存档存在浏览器的 `localStorage` 里，并不在服务器中。

也就是说，你正常关掉标签页、关掉浏览器，然后再回来，一般还在。

但前提是还是用的这个浏览器、这个地址访问地址。

如果清除了浏览器站点数据，或使用无痕模式，或更换了网址端口，或干脆换了浏览器，那么可能就真的没了。
