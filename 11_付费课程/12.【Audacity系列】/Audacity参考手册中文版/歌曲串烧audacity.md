歌曲串烧audacity



你说的就是**2016年"极限挑战公益联欢会"（极限公益演唱会）**上，黄渤与庾澄庆（哈林）合唱的那首**串烧组曲《水手》**，也常被叫"哈渤组合串烧"。

------

> 整首串烧以《水手》的旋律和歌词为主线，把6首经典歌曲无缝串联在一起，所以统称**《水手》串烧**。

------

## 关键信息

- **演出时间**：2016年
- **场合**：极限挑战公益联欢会（压轴曲目）
- **演唱者**：黄渤 + 庾澄庆
- **亮点**：黄渤当时带病上场，但表现非常稳，被网友称为"洗脑神曲"，"哈渤组合"由此出圈。





=========================



这个串烧之所以听起来浑然一体，核心靠两件事：**变调统一调性 + 淡入淡出无缝衔接**。下面按每首歌拆解变调逻辑，再给你一套Audacity操作流程。

------

## 一、各首歌如何变调、如何串接

这个串烧的主线是《水手》（郑智化），全曲统一在 **G调（或Gb）** 附近演唱，所以每首歌都被拉到了这个调上。

| 序号 | 歌曲             | 原调                 | 串烧中的调               | 变调方式                 | 串接手法                              |
| ---- | ---------------- | -------------------- | ------------------------ | ------------------------ | ------------------------------------- |
| ①    | 磨剪子嘞戗菜刀   | 民间吆喝（无固定调） | G调                      | 人声哼唱即定调，无需变调 | 口语念白 → 直接进《水手》前奏         |
| ②    | **《水手》**     | **Eb调**             | **→ 升到 G调（+3半音）** | 升3个半音                | 主线，首尾各出现一次，作为框架        |
| ③    | 《上海滩》       | 原调Dm/F             | → 升到 G调（+5半音）     | 升5个半音                | 《水手》尾奏渐弱 → 《上海滩》前奏淡入 |
| ④    | 《热情的沙漠》   | 原调Em               | → 升到 G调（+3半音）     | 升3个半音                | 副歌尾音延长 → 淡入下一首             |
| ⑤    | 《蓝精灵》       | 原调C                | → 升到 G调（+7半音）     | 升7个半音（近纯五度）    | 旋律衔接处重叠2秒，交叉淡化           |
| ⑥    | 《辣妹子》       | 原调G                | → 保持 G调               | 无需变调                 | 节奏加速，直接衔接                    |
| ⑦    | 《啊，朋友再见》 | 原调Am               | → 升到 G调（+2半音）     | 升2个半音                | 尾音长音 → 渐弱 → 回到《水手》        |
| ⑧    | 《水手》尾声     | Eb → G               | 同②                      | 同②                      | 首尾呼应，闭环                        |

**关键规律**：所有歌都被拉到 **G调**，所以听起来像"一首歌"。变调幅度在 **+2 ~ +7个半音** 之间，这个范围内人耳不会觉得突兀。

## 二、Audacity 制作流程（逐步操作）

### 准备工作

- 把8首歌下载为 MP3/WAV（44100Hz, 16bit以上）
- 确认每首歌的BPM（可用Audacity看波形密度，或在线查BPM）

### Step 1：全部导入多轨

```
文件 → 导入 → 音频 → 选全部8首 → 打开 
```

每首歌会自动占一条轨道。

### Step 2：变调（核心）

对每首歌单独操作：

```
选中某一轨 → 效果 → 改变音高（Change Pitch） 
```

| 歌曲               | 设置      |
| ------------------ | --------- |
| 水手（Eb→G）       | +3 半音   |
| 上海滩（Dm→G）     | +5 半音   |
| 热情的沙漠（Em→G） | +3 半音   |
| 蓝精灵（C→G）      | +7 半音   |
| 辣妹子（G→G）      | 0（不动） |
| 啊朋友再见（Am→G） | +2 半音   |

> ⚠️ **变调幅度别超过 ±6 半音**，否则音色会失真。蓝精灵 +7 半音略猛，可分两次：先 +5，再微调。

### Step 3：截取每首歌的精华片段

用 **时间选择工具**（快捷键 F1）框选要保留的部分，然后：

```
编辑 → 删除（Delete） 
```

只留你要的那一段。比如《水手》留副歌段，《上海滩》留"浪奔浪流"那段。

### Step 4：排列顺序、对齐节奏

把各轨拖到正确顺序。关键技巧：

- 选 **时间移位工具**（快捷键 F5），拖动整段音频对齐节拍
- 两首歌之间 **重叠 1~2 秒**（这是无缝的关键）

### Step 5：淡入淡出衔接（最重要）

**方法A：手动交叉淡化（推荐）**

1. 选中第一首歌 **最后2秒** → `效果 → 淡出（Fade Out）`，时长设 2秒
2. 选中第二首歌 **开头2秒** → `效果 → 淡入（Fade In）`，时长设 2秒
3. 因为有1~2秒重叠，淡出+淡入自然形成交叉淡化

**方法B：跨轨淡化（Audacity 3.x+）**

```
选中两轨重叠区域 → 效果 → 跨轨淡化（Crossfade Tracks） 
```

一次搞定，更丝滑。

### Step 6：统一音量

```
效果 → 标准化（Normalize）→ 设为 -1 dB 
```

或用 **效果 → 压缩器（Compressor）** 让各段音量一致。

### Step 7：导出

```
文件 → 导出 → 导出为 MP3 
```

或导出 WAV 保留无损音质。

## 串烧结构一览

```
吆喝 → 水手① → 水手② → 上海滩 → 水手过渡 → 热情的沙漠 → 水手过渡 → 蓝精灵 → 水手过渡 → 辣妹子 → 水手过渡 → 啊朋友再见 → 水手尾声（闭环） 
```

**核心手法**：每次切换歌曲，都用《水手》的 **"听见水手说"** 作为触发器，让听众感觉是"水手在说话时顺便唱了别的歌"，所以整体听起来像一首歌。

你如果要在Audacity里做，就是把上面每段分别截取为独立音频，用"听见水手说"那句做交叉淡化点，就能还原现场效果。

## Audacity中使用这些简谱的操作建议

| 用途         | 操作                                                         |
| ------------ | ------------------------------------------------------------ |
| **对音高**   | 用"效果→改变音高"，对照上面的半音数：Eb→G(+3)、Dm→G(+5)、Em→G(+3)、C→G(+7)、Am→G(+2) |
| **截取片段** | 用时间选择工具框选对应歌词段落，删除多余部分                 |
| **对节奏**   | 根据简谱节拍（4/4或2/4）手动对齐波形                         |
| **衔接**     | 在"听见水手说"处做2秒交叉淡化，即为现场效果的关键            |

简谱中 `1=G` 表示所有音符均以G为do，你在Audacity里变调时，目标统一设为G调即可。
