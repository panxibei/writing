不过不管是不是能将数学学到顶尖，还是说资质平平，平时只能应付个考试，那都不重要，关键是我们也得将数学到底怎么能学好给真正搞懂。

否则，以现在孩子们的教材水平以及考试要求，恐怕连及格都将是很困难的事。



好，我们说数学能力并不是一般人认为的解题做题能力，而是什么呢？

是能将世界万物模型化、抽象化的能力。

你看数学公式，它是怎么来的？

就是将某些研究的事物，把它抽象化，去掉一些不必要的条件因素，最后形成一个公式。

然后用公式来模拟这种事物的现象或状态变化，以此更方便研究事物。

就是这么简单一件事！

谁能将研究对象搞出一个模型，就是数学模型，你用公式也好，用图形也罢，都可以，那么你就是真正懂数学的。

好，那我们怎么才能做到这一点呢？



答案其实就是，要让孩子们从小多接触大自然，与万事万物亲密接触。

原因很简单，孩子们在头脑中产生各种各样的，包括立体的、更多维度的想象和记忆，那么就可以将这些东西进行转换、模拟，最终形成抽象化的普遍适用的数学模型、公式、图形等等。

和前面说的一样，谁能将现实世界中的东西平滑地转换成大脑中的抽象物，那么就是一个数学家。

我们看到的现在人类拥有的一切公式、定理，全是这么来的。

你想想是不是？

所以，我们让孩子去背公式，可不能简单粗暴死记硬背，因为那样最多能做些死题目，其他并无益处。

网上有一些猜饮料的火爆短视频游戏，玩法并不复杂，找张桌子，在桌子下面放上一排不同品牌、不同颜色、瓶子形状也各不相同的饮料。

然后在桌子上面也摆上一排饮料，但是要与桌子下面放的数量相同，只是顺序不同。

当然，桌子下面的饮料是被遮住的，接着就让你通过尝试摆放桌子上面的饮料的不同顺序来猜是否与桌子下面的饮料顺序一致。

游戏期间有一名裁判，在每一轮摆放完成后，裁判会观察并提供给游戏者同时位置正确、饮料也一致的数量。

如果所有位置的饮料都摆放一致，则游戏胜利完成！

这类游戏用的道具可以是五花八门，不局限于饮料瓶，大家可以到网上搜索一下看看。



为了让大家比较直观地了解这里面的数学原理，我们的目的就是要将一个玩的游戏，看看它能不能模型化，这就可以达到我们学数学，抽象思维的目的。

好，我们来个简单点的。

比如，我这儿一共有三种饮料：可乐、雪碧、酸奶。

为了方便表述，我们将它们符号化，也就是用字母来表示。

当然你也可以用其他抽象符号，甚至是用红、绿、白这种颜色来区分也行。

这也是数学抽象思维的一步。

```
可乐，用字母 A 来表示
雪碧，用字母 B 来表示
酸奶，用字母 C 来表示
```



好，在桌子下面我们可以这么放：

```
A|B|C
```



如果在桌子上面，我们这么放：

```
C|B|A
```

那么摆对的数量就为 `1` ，因为从左往右第二个，也就是只有中间那个位置的 `B` 是摆放正确的。



同样，如果桌子上面我们摆成了这样：

```
C|A|B
```

那么摆对的数量为 `0` ，因为一个也没对上。



好了，明白了吧？
