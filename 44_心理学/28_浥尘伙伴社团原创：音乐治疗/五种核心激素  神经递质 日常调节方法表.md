# 五种核心激素 / 神经递质 日常调节方法表

### 通用调节原则（适用于所有激素 / 神经递质）

1. **节律优先**：固定作息（睡眠 / 三餐）是激素平衡的基础，比单一方法更有效；
2. **适度不极端**：所有方法均为 “微小行为”，无需刻意坚持长时间，避免因难以执行而放弃；
3. **组合调节**：压力大时可同时「降皮质醇 + 升催产素 + 升血清素」（如拥抱 + 晒太阳 + 478 呼吸），协同效果远大于单一调节。
