赵小明“象思维”课程练习计划



以下为基于赵小明 “象思维” 核心理论（观象 - 取象 - 立象 - 换象）整理的**7 天入门练习计划**，每日含 1 个核心主题 + 3 个可直接实操的任务，聚焦从 “语言逻辑” 切换到 “图像 / 隐喻 / 整体关联” 的思维模式，无额外理论铺垫，直接上手练习。

------

### 赵小明象思维 7 天入门练习计划（每日 15-20 分钟）

#### 第 1 天：破除语言依赖，建立 “心象” 感知

**核心主题**：理解 “名可名，非常名”，拒绝文字定义，直接感知事物 “本象”。

- 任务 1（5 分钟）：无标签观察

  

  选 1 个日常物品（杯子 / 钥匙 / 手机），

  只看不说、只感不定义

  ：观察颜色、形状、光影、触感，大脑中

  不出现任何文字标签

  （如 “这是杯子”），纯感知 “它的存在”。

- 任务 2（7 分钟）：闭眼心象重现

  

  闭眼，在脑中

  完整还原物品的 360° 心象

  ：先正面，再侧面、背面，最后想象它在手心缓慢旋转，细节清晰可见（如杯口纹路、按键凹凸）。

- 任务 3（8 分钟）：万物关联联想

  

  看着物品，

  不做逻辑推理，只做自由关联

  ：它像什么自然物？（杯子像树洞 / 花苞）它给你什么感觉？（温暖 / 坚硬 / 流动）把关联画面

  直接画成简笔画

  ，不写文字。



#### 第 2 天：取象训练 —— 从具象到 “意象” 提炼

**核心主题**：从具体事物中提取 “核心象”，脱离实体，保留本质特征。

- 任务 1（6 分钟）：特征剥离游戏

  

  选 1 个动物（猫 / 鸟 / 鱼），写下它的

  3 个最核心特征

  （如猫：灵动、柔软、夜行），然后

  擦掉动物名称

  ，只看特征，在脑中生成一个

  无实体的 “意象符号”

  （如灵动 = 曲线、柔软 = 云朵、夜行 = 深色块）。

- 任务 2（7 分钟）：成语 / 概念转意象

  

  选 1 个抽象词（如 “焦虑”“平静”“突破”），

  不查定义，直接生成心象

  ：焦虑 = 乱线团 / 乌云；平静 = 湖面 / 满月；突破 = 破壳 / 破土。把意象

  画成极简符号

  （1-2 笔完成）。

- 任务 3（7 分钟）：生活场景取象

  

  回忆今天 1 个典型场景（上班 / 吃饭 / 聊天），

  忽略细节，提取 1 个核心意象

  ：上班 = 流水线 / 齿轮；吃饭 = 容器盛水；聊天 = 水流交汇。用 1 个

  图形符号

  代表该场景。



#### 第 3 天：立象训练 —— 用 “象” 替代逻辑思考

**核心主题**：遇到问题时，**先立象、再思考**，用图像 / 隐喻替代线性逻辑推导。

- 任务 1（5 分钟）：问题转象

  

  写下 1 个小困扰（如 “工作效率低”“人际关系紧张”），

  不分析原因，直接生成核心象

  ：效率低 = 堵车 / 卡壳；关系紧张 = 刺猬 / 结冰。把象

  画在纸中央

  。

- 任务 2（8 分钟）：象中找关联

  

  围绕核心象，

  自由联想 3 个相关象

  （如堵车→红灯 / 车流 / 修路；刺猬→刺 / 蜷缩 / 距离），把关联象

  画在核心象周围

  ，用线条连接，

  不写文字解释

  。

- 任务 3（7 分钟）：象的直观结论

  

  看着画好的 “象群图”，

  不做逻辑分析，直接说出 1 个直觉结论

  （如堵车→“需要暂停调整”；刺猬→“保持边界”），

  结论必须是从象中直接读出，而非推理

  。



#### 第 4 天：阴阳象思维 —— 掌握 “对立共生” 的整体观

**核心主题**：象思维的核心是 “阴阳一体”，看事物**同时见正反、动静、显隐**。

- 任务 1（6 分钟）：单一事物找阴阳

  

  选 1 个物品（如 “笔”），

  同时生成它的阴阳二象

  ：阳 = 书写 / 伸出 / 动；阴 = 收纳 / 隐藏 / 静。把阴阳二象

  画成对称图形

  （如太极图两半），标注阴阳（不写文字，用颜色区分：黑 = 阴、白 = 阳）。

- 任务 2（7 分钟）：场景阴阳转换

  

  回忆 1 件事（如 “一次争吵”），

  分别画出 “阳面”（表面行为：大声、愤怒）和 “阴面”（底层需求：渴望被理解、害怕被忽视）

  ，两张图并排，

  感受阴阳共生、不可分割

  。

- 任务 3（7 分钟）：阴阳平衡直觉

  

  看着阴阳图，

  不分析，直接感受 “平衡点”

  ：笔的阴阳平衡 =“用与藏的适度”；争吵的阴阳平衡 =“表达与倾听的对等”。把平衡点

  画成一个小圆点

  在阴阳图中心。



#### 第 5 天：五行象思维 —— 建立 “万物关联” 的系统观

**核心主题**：用五行（木火土金水）之象，理解事物**相生相克、动态关联**。

- 任务 1（5 分钟）：五行基础象记忆

  

  闭眼，在脑中生成五行

  核心象

  ：木 = 生长 / 向上 / 枝叶；火 = 温热 / 光明 / 火焰；土 = 承载 / 稳定 / 大地；金 = 收敛 / 坚硬 / 金属；水 = 流动 / 寒凉 / 水滴。每个象

  停留 3 秒，强化心象

  。

- 任务 2（8 分钟）：生活事物归五行象

  

  选 3 个日常事物（如 “桌子、灯光、河流”），

  不查五行属性，直接凭象归类

  ：桌子 = 木（生长、支撑）；灯光 = 火（光明、温热）；河流 = 水（流动、寒凉）。画出事物，旁边画对应五行象符号。

- 任务 3（7 分钟）：五行关联联想

  

  选 1 个事物（如 “木 = 树”），

  联想它的相生（水生木）、相克（金克木）之象

  ：水生木 = 雨水滋养树；金克木 = 斧头砍树。把相生、相克象

  画在树的两侧

  ，形成动态关联图。



#### 第 6 天：换象训练 —— 打破固有认知，重构思维

**核心主题**：象思维的灵活性在于 “换象”——**同一事物，可换不同象解读，突破思维定势**。

- 任务 1（6 分钟）：同一事物多象转换

  

  选 1 个熟悉事物（如 “手机”），

  生成 3 个完全不同的象

  ：①工具象（通讯器）；②容器象（信息盒子）；③桥梁象（连接人与人的线）。每个象

  画成不同风格的简笔画

  ，不重复。

- 任务 2（7 分钟）：负面事件换正向象

  

  回忆 1 件负面小事（如 “被批评”），

  先画负面象（乌云 / 石头），再换 1 个正向象（镜子 / 肥料）

  ：镜子 = 照见不足；肥料 = 滋养成长。感受

  换象后情绪与认知的变化

  。

- 任务 3（7 分钟）：问题换象找新解

  

  写下 1 个小难题（如 “学习记不住”），

  先画固有象（死记硬背 = 硬塞），再换 1 个新象（吸收 = 浇水灌溉）

  ，从新象中

  直接读出 1 个新方法

  （如 “反复复习 = 持续浇水”）。



#### 第 7 天：整合应用 —— 用象思维解决实际小问题

**核心主题**：综合前 6 天训练，**完整走 “观象→取象→立象→阴阳 / 五行关联→换象→得直觉结论” 流程**，解决 1 个实际小问题。

- 任务 1（8 分钟）：问题立象 + 关联

  

  选 1 个当前小问题（如 “时间不够用”）：①观象：感受问题的整体状态；②取象：提炼核心象（如 “时间 = 水流”）；③立象：画出水流核心象；④关联：补充阴阳（快 / 慢）、五行（水）关联象。

- 任务 2（7 分钟）：换象重构

  

  对核心象（水流）

  做 2 次换象

  ：①水流→容器（时间需收纳）；②水流→道路（时间需规划）。画出 2 个新象，感受不同解读视角。

- 任务 3（5 分钟）：直觉结论 + 行动

  

  从所有象图中，

  直接读出 1 个直觉结论 + 1 个具体行动

  （如结论：“时间需分段收纳”；行动：“每天分 3 段，每段专注 1 件事”），

  行动必须从象中直接生成，非逻辑推理

  。



### 练习核心原则（赵小明强调）

1. **先象后理**：**永远先生成心象，再做逻辑思考**，拒绝 “先定义、再想象”。
2. **无对错，只直观**：象思维是**直觉思维**，没有 “正确象”，只有 “你的象”，尊重第一直觉。
3. **轻量高频**：每天 15-20 分钟，**坚持比时长重要**，重点是切换思维习惯。
