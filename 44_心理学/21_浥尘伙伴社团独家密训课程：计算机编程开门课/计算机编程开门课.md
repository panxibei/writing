一、计算机的发明



### 朱传榘简介

**基本信息**：

- **姓名**：朱传榘（Chuan Chu Chu）
- **出生日期**：1919年6月12日
- **逝世日期**：2011年6月6日
- **出生地**：中国天津
- **毕业院校**：明尼苏达大学、宾夕法尼亚大学
- **主要成就**：被誉为“计算机先驱”“计算机之父”之一，参与设计世界上第一台通用电子计算机ENIAC，并首次实现了通用计算机的逻辑结构设计。

### 朱传榘的主要贡献

1. ENIAC计算机的逻辑结构设计

   ： 

   - 朱传榘在1945年与团队共同设计了世界上第一台通用电子计算机ENIAC（Electronic Numerical Integrator And Computer）。
   - 他创造性地使用二进制逻辑和电子线路，将ENIAC从单纯的算术计算器转变为能够处理多种逻辑问题的通用计算机，这一设计奠定了现代计算机的基本逻辑结构。

2. 计算机技术发展推动

   ： 

   - 朱传榘在ENIAC之后，继续参与计算机技术的研发和推广，为计算机科学的发展做出了重要贡献。
   - 他提出的逻辑设计思想，对后续计算机的架构和功能扩展产生了深远影响。

3. 教育与人才培养

   ： 

   - 朱传榘在计算机科学领域有着深厚的学术造诣，他致力于培养新一代的计算机科学家和工程师。
   - 他的教学和研究工作，为计算机科学领域输送了大量优秀人才。

### 朱传榘的荣誉与认可

- **计算机先驱奖**：1981年，朱传榘因在计算机领域的杰出贡献，被授予“计算机先驱奖”（Computer Pioneer Award），这是对他卓越成就的认可。
- **国际影响力**：朱传榘的工作不仅在美国计算机科学界产生了深远影响，也在全球范围内推动了计算机技术的发展。他的贡献被国际计算机科学界广泛认可和赞誉。

### 朱传榘的个人品质与精神

- **创新精神**：朱传榘在计算机科学领域展现出了卓越的创新精神，他的逻辑设计思想为计算机技术的发展开辟了新的道路。
- **坚韧不拔**：在面对技术难题和挑战时，朱传榘始终保持着坚韧不拔的精神，不断探索和尝试新的解决方案。
- **国际视野**：朱传榘具有广阔的国际视野，他积极参与国际计算机科学界的交流与合作，为推动全球计算机技术的发展做出了贡献。











二、计算机基本组成

冯・诺依曼体系结构

图a01



冯·诺依曼体系结构主要由以下五个核心部分组成：

1. 运算器（ALU，算术逻辑单元）
   - **功能**：负责执行算术运算（如加、减、乘、除）和逻辑运算（如与、或、非、比较）。
   - **作用**：是计算机进行数据处理的核心部件。
2. 控制器（CU，控制单元）
   - **功能**：从存储器中取出指令，进行译码，并根据指令控制计算机各部件协调工作。
   - **作用**：相当于计算机的“大脑”，指挥和控制计算机的运行。
3. 存储器（Memory）
   - **功能**：用于存储程序和数据，包括内存（主存）和外存（如硬盘、U盘等）。
   - **特点**：采用随机存取方式，可按地址直接访问任意存储单元。
   - **作用**：是计算机的“记忆库”，保存程序执行所需的信息。
4. 输入设备（Input Devices）
   - **功能**：将外部信息（如键盘输入、鼠标操作、扫描仪读取的图像等）转换为计算机能够识别的二进制代码，并送入存储器。
   - **示例**：键盘、鼠标、扫描仪、摄像头等。
5. 输出设备（Output Devices）
   - **功能**：将计算机处理后的结果（如文本、图像、声音等）转换为人类或其他设备能够识别的形式。
   - **示例**：显示器、打印机、音箱等。

### 工作原理

冯·诺依曼体系结构的工作原理可以概括为“存储程序”和“程序控制”：

- **存储程序**：将程序和数据以二进制代码的形式预先存储在存储器中。
- **程序控制**：计算机在运行时，控制器从存储器中逐条取出指令，进行译码，并根据指令控制运算器、存储器、输入设备和输出设备协同工作，完成程序规定的任务。

### 特点与优势

1. **程序与数据共存**：程序和数据以同等地位存储在存储器中，可按地址寻访。
2. **顺序执行**：指令按顺序执行，由控制器控制执行流程。
3. **通用性强**：通过编制不同的程序，计算机可以完成各种不同的任务。
4. **易于扩展**：可根据需要增加存储器容量、扩展输入输出设备等。

### 局限性

尽管冯·诺依曼体系结构具有诸多优势，但也存在一些局限性：

1. **冯·诺依曼瓶颈**：CPU与存储器之间的数据传输速率有限，成为制约计算机性能提升的瓶颈。
2. **串行执行**：指令按顺序执行，难以充分利用计算机的并行处理能力。

### 现代计算机中的改进与发展

为了克服冯·诺依曼体系结构的局限性，现代计算机在设计和实现上进行了诸多改进：

1. **采用高速缓存（Cache）**：在CPU与主存之间增加高速缓存，提高数据传输速率。
2. **流水线技术**：将指令执行过程划分为多个阶段，并行处理多条指令。
3. **多核处理器**：在一个芯片上集成多个处理核心，提高并行处理能力。
4. **非冯·诺依曼架构探索**：如数据流计算机、归约机、智能计算机等新型架构的研究与探索。

五、编程

编程归根结底，就是对前面所说的这些东西进行操控，包括数据和设备。



所有机器都有一张操作命令清单，让你可以控制它。

有时这个清单非常简短。

电水壶就只允许两种操作：打开和关闭。

CD播放器稍微复杂点，除了打开和关闭以外，还能调节音量、播放、暂停、快进、快退、随机播放等。



计算机和其他机器一样，也有一张操作命令清单。

比如，可以命令计算机把两个数相加。

这种操作命令的总和就是计算机的机器语言（machine language）。



计算机刚发明的时候，所有程序就是一条条机器语言的命令。

没过多久，程序就改成使用汇编语言了，它要比机器语言写起来稍微方便一点。命令清单还是一样的，就是每个命令换了一个更人性化的名字。

机器语言的加法命令是11001101，这可能就是计算机内部的加法表达方式，但是在汇编语言中，这条命令就改成了add。



机器语言和汇编语言的共同问题就是，只能让大多数计算机做一些很简单的事情。

比如，假定你想让计算机的蜂鸣器响10次，但是不存在一条直接的机器语言命令让电脑重复进行n次操作，所以只能用机器语言写出下面这样的程序：



```
	x<-10			// 将数字10存入内存地址0
a:	if x<0 goto b	// 如果内存地址0的值为负数，跳到b行
	ring			// 蜂鸣器发出声音
	x-1				//将内存地址0的值减1
	goto a			// 跳到a行
b:
	……程序的其他部分……
```



如果只是为了让蜂鸣器响10次就不得不写这么多代码，不难想象写出一个文字处理器或电子表格将是一项多么浩大的工程。

顺便说一句，请再看一下上面的程序。蜂鸣器真的会响10次吗？不，响了11次。

我不应该在第一行使用10，而应该使用9。

我故意在这个例子中留了一个bug，证明编程语言的一个重要特点：一个操作所需的代码越多，就越难避免bug，也越难发现它们。



高级语言

```
dotimes 10	// 蜂鸣器响
```
