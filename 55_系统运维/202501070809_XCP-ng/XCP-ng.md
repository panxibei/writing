我抬手看表，万幸赶在了9点之前。

我气喘吁吁，上前叩打门环。

过了好一会儿，大门开了一条缝，一名管家模样的人探出脑袋来。

“你找谁？”

我连忙躬身施礼，“老人家，鄙人姓贾，贾部廖。”

“昨日张大人召在下府上议事，约在今日，烦请老人家代为通禀！”

“哦，您就是贾大人啊！”

“嘿嘿，正是，正是……”

“好，容我禀明大人，请贾大人在此稍后！”

“有劳有劳！”



约莫一盏茶的功夫，老管家回来了，随后就将我引入府内。

进了这座宅院，我才知道什么叫做“大”！

好家伙，两个人穿堂过屋，这大大小小的屋子不下几十间。

走了好一阵，我俩来到了一条走廊下。

老管家指了指廊下的一间屋子，“就请贾大人在此书房等候！”

互相礼过之后，老管家便自行离去。



我迈步进了书房，嚯，眼前的一幕让我有点发懵。

这书房倒是像个书房，只是这屋子收拾得也太干净了。

整个屋子里，只有一张方桌和一把太师椅，桌上放着一本薄薄的册子，除此之外别无他物。

也许这只是张大人最不常用的书房吧。

我垂手恭敬地站着，时间一久心中不免胡思乱想。



又过了挺长时间，忽觉腹中饥饿。

看了看表，已是中午时分。

“想必张大人公务繁忙，此时正是用餐时间，或许过一会儿就来了，我还是忍忍吧！”





走到门口，有心高声招呼一下老管家，又恐举止不雅惊扰了他人。

左也不是，右也不是，不免心生烦躁。于是我就围着书桌转了起来。

结果，四周白墙，空无一物，得还是一个“等”字。



没想到，这一等，又是一两个时辰。

怎么还没来？

我是又累又饿，两眼发花，只好一屁股坐在太师椅上。

我有心离开，又怕错过后张大人责怪。

好吧，忍一时风平浪静啊！



哎？这是什么？

我一眼瞅着了桌子上的那本册子，顺手就给拿了起来。

这写的什么？

反正什么也做不了，与其干等，不如看看这册子打发一下时间吧！

于是我好奇地翻开了那本册子。

“虚拟机 `XCP-ng` 大教程……”



`XCP-ng` 是一套用户友好、高性能的虚拟化解决方案，为不受限制的功能和开源可访问性而协同开发。

`XCP-ng` 基于 `Xen Server` 虚拟系统，不同于我们熟知的 `VMware` 或 `KVM` 等常见的虚拟系统，它是立足于 `Xen` 云平台的下一代虚拟系统。



官网：https://xcp-ng.org/

图a01





哦？这我倒是头一次听说，接着往下看。

和其他虚拟机系统类似，可以到官网上下载安装程序。

目前有两个版本，一个是 `8.2 LTS` ，也就是长期服务版，还有一个是最新版本 `8.3` 。

图a02



`XCP-ng` 虚拟系统安装包是以 `ISO` 形式发布的，因此可以将它刻录到光盘，也可以放在U盘里安装，形式多样。

我看了看窗外，似乎还是没有动静。

后面 `XCP-ng` 的安装过程与其他虚拟系统大同小异，被我略过……

不过这并不是最好的管理方式，其实可以用一个叫作 `XCP-ng Center` 的程序来管理。

这个 `XCP-ng Center` 是用 `C#` 写的，可以运行在 `Windows` 平台上，用来管理或迁移虚拟机，这一点和其他虚拟系统也很类似。

`XCP-ng` 在创建虚拟时与其他几种虚拟系统有所不同。

先是创建一个虚拟存储池 `SR` ，然后再是创建虚拟机 `VM` 。

我目不转睛，想看看具体这玩意是怎么玩的。



右键点击对象服务器，点选 `New SR...` 来创建一个虚拟存储池。

虚拟存储池有多种形式，通常我们常用的就是 `Windows` 文件共享。

因此我们选择 `Windows File Sharing (SMB/CIFS)` 。

哈哈，看来这套开源的虚拟系统也挺有意思的嘛！

没想到寂寞难耐之时，还能看到这般有趣的东西。

不知不觉，太阳西转，我一看表，已是快5点60了！



我合上册子，起身正欲查看屋外情况。

这时老管家推门进来，一边作揖，一边面带愧色。

“贾大人，抱歉抱歉，让您久等了！”

“实不相瞒，我家老爷家务缠身，至今仍未得闲，恐怕没有时间来见贾大人了！”

“老爷吩咐，还请贾大人先行回府，改日必登门致歉！”

“贾大人，这边请！”



看来是白来一趟啊！

当天傍晚时分，我悻悻地离开了。



过了大概半月有余，我忽然接到单位委派，作为主考官要对一批今年刚毕业的青年才俊进行选拔。

考试结束后，当我阅卷之时，冷不丁发现有一道题目：请谈一谈你熟悉的虚拟机系统。

我愣了一下，随后灵光乍现，似乎突然想起了什么。

正值半夜，其他考官都去休息了，我看四下无人，疯狂地翻阅起桌子上的一堆一堆试卷。

最后，终于被我找到了那张写有 `XCP-ng` 的考卷。

我长出了一口气，嘴角也露出了满意的微笑……
