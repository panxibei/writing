“咚咚咚……咚咚咚……咚咚咚……”

一阵催命式的砸门声传来，我脑袋嗡嗡作响，手里的绳子愣是吓得抖落在了地上。

大晚上的，这TM是谁啊，我怒气值快速上升。

打开门一看，是位70左右的老太太，上上下下收拾得干净利索。



“您……您找……？”

“小伙子，哈哈，我就找你啊……”

“您是……？”

“你是不是刚搬过来的？”

我张着嘴，“啊”了一声。

“太好了！快，快帮我看看手机，我不会弄啊！”

说完就往里闯……



不是，我一头雾水，不知道怎么回事，心想这老太太是一点也不见外啊！

后来我才从她的只言片语中得知，她是个独居老人，就住在楼上，只有一个女儿，在国外工作。

她来找我，是因为她不会用手机，挨家挨户敲门，正好我给开了门。



“小伙子，我要买暖宝宝，我不会操作，你帮我看看哈！”

我皱了皱眉，心想赶快打发了就得了。

我调整了一下表情：“好，阿姨，您看啊，是这样操作，您记着点……哎？这不是有购买记录吗？”

老太太咧嘴笑道：“这……这应该是上次我女儿给我买的，你就说怎么操作吧……”

终于，把老太太搞定了。

临走时也没说声谢谢，不过没关系，我继续我的……



我弯腰捡起地上的绳子，望了望房顶，正考虑下一步该怎么办。

这时又是一阵敲门声，这动静和刚才有得一拼，我的怒气值瞬间又回到了高点。

我压了压火，扔下绳子，打开门一看，嘿，还是那位老太太！

“嘿嘿嘿……小伙子，不好意思啊，反正你也没事，你再帮我看看电脑吧！”

我顿时瞪圆了眼珠子，温柔地说道：“好……！好……！”



“哎，这有个程序，非要用什么IE浏览器才能打开，你帮我瞧瞧，我不懂……”

我一看，是Win11系统，就给老太太解释，你用edge浏览器，然后打开IE模式就行了。

结果这老太太不乐意了，说昨天找过隔壁老王，他也是这么说的，结果根本没啥用。

老太太不依不饶，说必须要IE浏览器，说什么别的也不行。

我心想，还好我是干这行的，虽然现在失业N个月了，但技术还在，今天我就给你露一手，赶紧让她回去吧！

我想到这儿，就跟老太太说：“阿姨，您别着急，我有办法！”

接着，我就边操作边给她解释……

老太太看着我自信满满的样子，轻轻点了点头。

“没想到啊，小伙子，你很厉害啊！帮我解决了大问题！”

老太太拿起电脑就要走，一边走一边还夸呢：“小伙子，我看好你哦，以后少不了要麻烦你哈！我走啦！”

我笑了笑：“阿姨，您客气了，您慢走哈！”

走到门口，老太太回头又说：“我真走了啊！”

“好，有什么需要，我尽力而为。”

“那，我的真走了哈……”

“好……”

“哎，你不挽留我一下？”

我再一次瞪圆了眼珠子……



关上门，安静了，我摇了摇头，望着那一捆绳子，长叹了口气。

夜已深，我想起了远在家乡的父母，不禁潸然泪下。

我一狠心，一咬牙，一跺脚，一把抄起绳子……



“咚咚咚……咚咚咚……咚咚咚……”

哎哟我的天哪——！！

“哗……”，我打开大门，门外居然还是那位缠人的老太太！

正要发作，不过这回有点不一样了，她手里端着个碗，正笑嘻嘻地瞅着我。



“呃……您这是……？”

老太太没搭理我，自顾自就往里面走。

她把碗往桌上一放，这才和我说：“小伙子，一个人出门在外不容易，你还没吃饭吧，我煮了点饺子，你尝尝吧！”

看我愣在那边，她就把心里话一股脑儿倒了出来。



原来，这老太太发现我刚搬来不久，孤身一人，白天也不见我上班。

后来跟街坊邻居一扫听，才得知我失业有好几个月，一蹶不振，天天郁郁寡欢。

今天又在楼道里擦肩而过，看我带了一捆绳子，眼角似乎还有泪痕，生怕我出什么意外，于是这才上演了刚才的一出戏。

我一边吃着饺子，一边听着老太太说话，心里暖暖的。

我很感激她对我的关心，我告诉她，流泪是因为我太想家了，很久没回家，这不准备元旦过后就回家看看父母。

之所以买了绳子，是因为租这破房子连个晾衣架都没有，没地方晒衣服啊！

谁叫我穷呢！
