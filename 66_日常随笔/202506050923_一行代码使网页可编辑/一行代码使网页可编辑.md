2058年，我带着两个徒弟去办事，经过一座不起眼的小镇子。

中午时分，本来就阴着个脸的老天忽然下起了蒙蒙细雨。

此时的我们，是又饥又累。



师父，我饿了，我们找个地方吃饭吧。

这里地处偏远，即便是镇子中心也就两排商铺。

再加上本无什么客人，两排商铺也关了大半，唯有一家某连锁品牌的小吃店开着。

我指了指这家小吃店，两徒弟咽了咽口水，加紧了脚步。



一脚迈进店家门口，喊了半天，不见店家。

转身看了了圈，收银台上一台电脑，显示着价目表。

我有些犹豫，最便宜的只有馄饨，论个卖，一块钱一个。

我摸了摸两边的口袋，比脸干净。

再掏了掏衣服里边的暗兜，块八毛的零碎，好歹凑齐了一块零二毛。

这可咋办？



瞅着俩小徒弟饿得直转圈，我这当师父的着实不是个滋味。

我盯着那电脑，心想，总不能只买一个馄饨三个人吃吧？

嘿，有了！

我突然灵机一动，发现这电脑上使用的联网系统，是通过浏览器呈现内容。



真是天助我也，给它改改不就完事了嘛！

师父，您开玩笑吧，这系统后台程序你怎么改？

少废话，帮我看着点人！



我转身来到电脑前，一顿操作，将一块钱一个，后面加个0，给改成了一块钱十个。

具体我是这么改的……







按下 `F12` ，打开浏览器控制台，输入以下代码，回车。

```
document.designMode = "on";
```



然后就可以在页面上随意修改了。

修改好后，可以将编辑功能关闭，输入以下代码后回车即可。

```
document.designMode = "off"
```



这个功能不但可以编辑文字，连图像都可以修改或替换。
