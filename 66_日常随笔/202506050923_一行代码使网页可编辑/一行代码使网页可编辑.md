2058年，我带着两个徒弟去办事，经过一座不起眼的小镇子。

中午时分，本来就阴着个脸的老天忽然下起了蒙蒙细雨。

此时的我们，是又饥又累。



师父，我饿了，我们找个地方吃饭吧。

这里地处偏远，即便是镇子中心也就两排商铺。

再加上本无什么客人，两排商铺也关了大半，唯有一家某连锁品牌的小吃店开着。

我指了指这家小吃店，两徒弟咽了咽口水，加紧了脚步。



一脚迈进店家门口，喊了半天，不见店家。

转身看了了圈，收银台上一台电脑，显示着价目表。

我有些犹豫，最便宜的只有馄饨，论个卖，一块钱一个。

我摸了摸两边的口袋，比脸干净。

再掏了掏衣服里边的暗兜，块八毛的零碎，好歹凑齐了一块零二毛。

这可咋办？



瞅着俩小徒弟饿得直转圈，我这当师父的着实不是个滋味。

我盯着那电脑，心想，总不能只买一个馄饨三个人吃吧？

嘿，有了！

我突然灵机一动，发现这电脑上使用的联网系统，是通过浏览器呈现内容。



真是天助我也，给它改改不就完事了嘛！

师父，您开玩笑吧，这系统后台程序你怎么改？

少废话，帮我看着点人！



我转身来到电脑前，一顿操作，将一块钱一个，后面加个0，给改成了一块钱十个。

具体我是这么改的……







按下 `F12` ，打开浏览器控制台，输入以下代码，回车。

```
document.designMode = "on";
```



然后就可以在页面上随意修改了。

修改好后，可以将编辑功能关闭，输入以下代码后回车即可。

```
document.designMode = "off"
```



这个功能不但可以编辑文字，连图像都可以修改或替换。



刚改好，从后面转出一个人来。

此人正是店主，见着我们三个，急忙笑脸相迎。

“您几位，吃点什么啊？”

“馄……馄饨……”

我没敢吱声，一旁的颜回搭了茬。



“嘿，今天您几位可来着了，我们最近推出的全新手工馄饨。”

“我们这有，、猪肉馅、牛肉馅、羊肉馅、鸡肉馅、鲜虾馅、鱼肉馅、蟹肉馅、韭菜鸡蛋馅、白菜豆腐馅、香菇青菜馅、胡萝卜木耳馅、猪肉白菜馅、猪肉香菇馅、牛肉芹菜馅、虾仁猪肉馅……”

“客官，需要哪些？”



子路饿的实在是撑不住了，不由自主地伸出一只大手，冲着掌柜的做了个一把抓的动作。

“哦哦……您的意思是，全都……要？”

我一把把子路拨愣到一边，猛地竖起一根手指怼到掌柜的脸上，当然是食指不是中指。

掌柜的虽然吓了一跳，不过仍然一副笑脸。

“您这是……？”

“来……一……一块钱的！”

“啊？一……一块钱？您三位？恐怕不太够吧？”

“少……少啰嗦……就……就……就……一块钱的，咋地，你还拒收人民币啊！”

“行行行……客官息怒，我照办就是了……”



我一扬脖，不是看不起掌柜那意思，倒是心多少有点虚。

此时我用眼角的余光向柜台望去，就看那掌柜收了一块钱，转身绕到柜台后面，往电脑屏幕上这么一看。

哎哟喂，好家伙，脸上的表情“唰”地，变了！

嘿，我有点不敢看，装住没事人一般，背着手往那靠窗户的座位踱去。



“哎？奇怪了，我明明记得是一块钱一个馄饨，怎么……”

“掌柜的，能不能快点？俺们还着急赶路呢！”

“好好好……马上就来！”



过了好一阵，馄饨终于上桌了！

我这两徒弟还算不错，就跟我说：“师父您辛苦，您四个，我们哥俩一人仨。”

我点了点头，紧接着三个人就狼吞虎咽起来。

然而再怎么狼吞虎咽，一共就三四个馄饨，几个大男人哪够吃饱啊！



还是子路这小子聪明。

他招呼掌柜的，询问煮馄饨的汤要钱不要，不要就给来几大碗。

就这样，我们几个人是你一碗我一碗给赛上了。



最后差不多得个半饱，抹了抹嘴起身就走。

掌柜的出来将我们给拦住：“客官……嘿嘿，还没给钱呢！”

“哦哦，糊涂……糊涂了……”

说完，我掏出那一块钱，递给了掌柜。

掌柜笑道：“客户莫开玩笑，10个馄饨10块钱。”



我勒了勒裤腰带：“你这店家，好生奇怪，明明写的是1块钱10个，如何问我要10块钱？”

这掌柜的眼瞅来势汹汹，也不敢惹恼我们，便自顾自地一边小声音嘀咕，一边转身来到柜台后面。

我没敢多说，一把拉着两徒弟就往外走。

过了几一会儿，我见走得挺远，已然望不见那小吃店，回过头来发狠道：“吃你10个馄饨算便宜你了，要是惹急了我，老子一字后面再加两个零，我吃你1000！”
