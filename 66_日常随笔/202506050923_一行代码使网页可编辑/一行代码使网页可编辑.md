西元2058年的一天，我带着两个徒弟去某地合作社办事，途径一座名不见经传的古镇。

中午时分，本就阴沉着脸的老天忽然下起了蒙蒙细雨。

无心欣赏古镇风情，三个人两手空空，拖着沉重艰难的步子，此时又饥又累。



“师父，俺们找个地儿吃饭吧……”

我环顾四周，眼前似乎就是镇子的中心地带了。

然而这里地处偏远，即便是镇子最热闹的地方也就两排寥寥无几的店铺。

再加上天公不美，本也没几名客人，店铺关了大半，唯有一家挂着某连锁品牌招牌的小吃店开着。

我如获至宝，冲着两个徒弟指了指那家小吃店。

二人顿时喜上眉梢，口水咽了又咽，各自加紧了脚步。



三人同时迈进店家门口，呼喊半晌，却不见店家。

我自顾自在店中转起了圆圈，只见凌乱的柜台上扔着一台电脑，屏幕亮着，显示的是价目表。

我凑近一瞧，心中犯了嘀咕，最便宜的只有白菜馅的馄饨，论个卖，一块钱一个。

我挨个摸着上下左右前后一共四五个的口袋，结果不出所料，比脸还干净。

徒弟看我那样，就问：“师傅，不见店家，您咋还跳起科目三了啊？”

我狠狠瞪了他俩一眼，突然想起衣服里边还有个暗兜。

赶紧掏了半天，大小零碎钢镚，拢共一块二毛。

我瞅了瞅他俩，早就饿得原地转圈眼发花，我这当师父的心里着实不是个滋味。

我盯着那价目表，心里琢磨，总不能只买一个馄饨仨人吃吧？

这可咋办？



嘿，我一拍大腿，有了！

我突然灵机一动，发现这电脑上使用的系统，是通过浏览器呈现内容。

着啊，真是天助我也，给它改改不就完事了嘛！

“师父，您开玩笑吧，这系统后台程序您怎么改？”

“少废话，你俩懂个P，赶紧的，给我盯着点！”

接下来我一顿操作，将1块钱1个，后面加个0，给改成了1块钱10个。

具体我是这么改的……





在浏览器界面下按下 `F12` ，即可打开浏览器控制台，然后输入以下代码，回车。

```
document.designMode = "on";
```



随后就可以在页面上任意修改了，就这么简单。

修改好后，可以将编辑功能关闭，输入以下代码后回车即可。

```
document.designMode = "off"
```



这个功能不但可以编辑文字，连图像都可以修改或替换。

嘿嘿，虽然简单，但一般人我还不告诉呢！

我刚改好，此时就从前厅后面转出一个人来。

此人一见有客人，急忙笑脸相迎，没错正是这家店的掌柜。



“哎哟，您几位，用点什么啊？”

“馄……馄饨……”

我没敢吱声，一旁的颜回赶紧搭了茬。



“嘿，今天您几位可来着了，本店最近全新推出的手工馄饨。”

“我们这有，猪肉馅、牛肉馅、羊肉馅、鸡肉馅、鲜虾馅、鱼肉馅、蟹肉馅、韭菜鸡蛋馅、白菜豆腐馅、香菇青菜馅、胡萝卜木耳馅、猪肉白菜馅、猪肉香菇馅、牛肉芹菜馅、虾仁猪肉馅……”

“就……啊……就……白菜馅……”



我也不知道小路是啥时候口吃的，可怜的娃，估摸着实在是饿得撑不住了。

“哦哦……您几位……要多少？”

一旁的小颜也熬不住了，不由自主地伸出两只手。

“哦哦……您的意思……一人来10个……？”



我一把把小颜拨愣到一边，猛地竖起一根手指怼在掌柜的眼前，当然是食指不是中指哈！

掌柜先是吓了一跳，后来仍一副笑脸地问道：“您这是……？”

“一……一块钱的！”

“啊？一……一块钱？您三位？恐怕不太够吧？”

“少……少啰嗦……就……就……就……一块钱的，咋地，你……你……还拒收人民币啊！”

“行行行……客官息怒，我照办就是……”

我也不知道我怎么学得小路口吃，说完话一扬脖，倒不是装横看不起掌柜那意思，实则心中有虚。



过了一阵，馄饨终于上桌了！

我这两徒弟还算不错，就跟我说：“师父您辛苦，您四个，我们哥俩一人仨。”

我点了点头，招呼他俩吃了赶紧赶路，接着三个人就狼吞虎咽起来。



然而再怎么说，一个人三四个馄饨，哪里够吃饱啊！

还是小路这小子聪明，呼啦就站起身来喊道：“掌柜的，馄饨汤有么，给俺们来几大碗。”

就这样，师徒几个是你一碗我一碗，给赛上了。



最后临了，几个人差不多得了个半饱，抹了抹嘴起身就往外走。

掌柜的出来将我们拦住：“客官……嘿嘿，还没给钱呢！”

“哦哦，糊涂……糊涂了……”

说完，我掏出那拼凑的一块钱，递给掌柜。

掌柜笑道：“客户莫开玩笑，10个馄饨10块钱，还少9块哩！”



我一听，勒了勒裤腰带，横眉立目道：“你这店家，好生奇怪，明明写的是1块钱10个，如何要得10块钱啊？”

俩徒弟也上来帮忙：“就是就是，你这玩店大欺客、坐地起价呀，俺们要到工商那儿告你乱收费哩！”

这掌柜的眼瞅来势汹汹，也不敢惹恼我们，便一边自顾自地小声音嘀咕，一边转到柜台后面。



我昂着脑袋偏向一边，心里却带着点虚，用眼角的余光瞥去，就看那掌柜收了一块钱的散碎钢镚，绕到柜台后面，往电脑屏幕上这么一看。

哎哟喂，好家伙，那脸上的表情“唰”地变了，一会儿红，一会儿紫！

不过，这掌柜的不愧是做生意的一把好手，由晴转阴，很快又由阴转晴。

远远地直冲我们拱手笑道：“三位客官，且请息怒，方才我查看了一番，定是这电脑出了故障，这次就算我请客，刚才多有得罪，请客官见谅……见谅！”



我没敢多说什么，一把拉着两徒弟就往外走。

“师父啊，这店家也忒小气，既然他电脑出了故障，光赔礼又有何用，倒不如让他再多送俺们馒头干粮啥的，也好路上充饥……”

“你快闭嘴吧，你是真傻还是装傻，师父方才作法你没看着啊，那叫一叶障目之术，把那店家唬住，俺们才得了一顿饭食，你还在这边卖乖！”



过了好半晌，我见走得遥远，已然望不见那小吃店，回过头来冲那方向发狠：“吃你10个馄饨算便宜了你，要是惹急了我，老子1字后面添两个0，我吃你100！”
