这个 `VxKex-NEXT` 是什么呢？

它是一套适用于 Windows 7 的 API 扩展，可让一些 Windows 8、8.1 和 10 独占应用程序在 Windows 7 上正常运行。

简单地说，就是让你可以在 `Win7` 上跑比较新的程序。



项目地址：

> https://github.com/xuzhongxing/VxKex-NEXT



这么神奇吗？

没错，据官网资料说明 `VxKex NEXT` 不会修改任何系统文件。

它对整个系统的影响极小，不使用后台服务，不安装全局钩子，加载的 `shell` 扩展和 `DLL` 影响也很小，可以随时禁用，完全可以确保当前的 `Windows 7` 一如既往的稳定性。

可能大家都 知道，`Windows 7` 官方早就不支持多年了。

因此大概率很多用户是没有任何更新的就这样直接使用 Windows 7 。

一般来讲，没有更新的状态下，可以使用`VxKex NEXT` ，通常问题不大。

不过也可能会遇到有些要求苛刻的软件，这时我们就需要安装一些更新补丁来支持软件的完美运行。

到目前为止，`VxKex NEXT` 只适用于 `Windows 7` 。

如果我们在 Windows 8 或 8.1 上跑 `VxKex NEXT` ，那是没有意义的。 



`VxKex NEXT` 的工作原理是在启用 `VxKex NEXT` 的每个程序中加载一个 `DLL` 。

这是通过使用 `IFEO`（图像文件执行选项）注册表键来实现的。

具体来说，`VerifierDlls` 值被设置为指向 `VxKex NEXT DLL` ，该 `DLL` 会加载到进程中。

`API` 扩展是通过编辑程序的动态链接库导入表来实现的，这样程序就不会从 `Windows 8/8.1/10/11` 动态链接库中导入，而是导入 `VxKex NEXT` 动态链接库。

这些 `VxKex NEXT` 动态链接库包含较新版本 `Windows` 中引入的 `Windows API` 函数的实现。

当然，不是太懂也没关系，直接用就是了。
