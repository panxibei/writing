他心想，人都跑没了，光有AI有什么用！

再说了，我电脑还是 `Win7` 系统，能安装上吗？

想到这儿，他打开了电脑，系统徽标闪烁了8分钟后电脑启动完成。

老陈在网上搜索了半天，好不容易下载了豆包，结果还真是遇到了麻烦。

在安装时，提示出错，无法继续安装。

小艾了解了老陈的实际需求，告诉他放心，`Win7` 是可以支持现在的很多新软件的。

不过在安装使用新软件之前，需要给 `Win7` 武装上一些新装备，好让它正确识别这些新软件。

具体怎么做呢？

这就不得不提 `VxKex-NEXT` 了！











项目地址：

> https://github.com/xuzhongxing/VxKex-NEXT













VxKex NEXT 不会修改任何系统文件。它对整个系统的影响极小。不使用后台服务，不安装全局钩子，加载的 shell 扩展和 DLL 影响也很小，可以随时禁用。您可以放心，您的 Windows 7 将一如既往地保持稳定。

没有任何更新的 Windows 7 用户仍可使用它，但许多程序需要安装 Service Pack 1、KB2533623（DllDirectories 更新）和 KB2670838（平台更新）才能运行。最好安装这些更新。



据说有以下三个更新补丁需要按顺序应用后才能使 `VxKex NEXT` 正常稳定工作。

* kb976932-x64

  > https://catalog.s.download.windowsupdate.com/msdownload/update/software/svpk/2011/02/windows6.1-kb976932-x64_74865ef2562006e51d7f9333b4a8d45b7a749dab.exe

  

* kb2670838-x64

  > https://catalog.s.download.windowsupdate.com/msdownload/update/software/ftpk/2013/02/windows6.1-kb2670838-x64_9f667ff60e80b64cbed2774681302baeaf0fc6a6.msu

  

* kb2758857-x64

  > https://catalog.s.download.windowsupdate.com/msdownload/update/software/secu/2012/10/windows6.1-kb2758857-x64_b717b4e2168ab84dda2eb17c71a4a1adee502ba6.msu





目前，VxKex NEXT 只适用于 Windows 7。如果您使用的是 Windows 8 或 8.1，VxKex NEXT 将毫无用处。 



VxKex NEXT 的工作原理是在启用 VxKex NEXT 的每个程序中加载一个 DLL。

这是通过使用 IFEO（图像文件执行选项）注册表键来实现的。

具体来说，“VerifierDlls”值被设置为指向 VxKex NEXT DLL，该 DLL 会加载到进程中。

API 扩展是通过编辑程序的动态链接库导入表来实现的，这样程序就不会从 Windows 8/8.1/10/11 动态链接库中导入，而是导入 VxKex NEXT 动态链接库。

这些 VxKex NEXT 动态链接库包含较新版本 Windows 中引入的 Windows API 函数的实现。
