前两天漂亮女租客执意要退房，我是一点儿都没拦着。

有人说了，这年头能把房子租出去就不容易了，你咋还把租客放跑了？

说实话，我也没招，要问我怎么回事，这话得从几个月前说起……



大概在半年前吧，已经空置大半年的房子好不容易迎来了一位女租客。

你还别说，这位女租客长得年轻漂亮，估摸着30岁刚出头，一看就是坐办公室的白领。

她说她单身一个人，爱干净、喜欢安静，于是就租给她了。

可没成想，在接下来的日子里，这位女租客总是借各种理由找我。

像是换个电灯啊，修个马桶啊，连个网络啊……

我就当这女租客动手能力差点，也没多想，就当上门帮个忙。

这一来二去，渐渐地在房子里呆的时间就越来越久，我也和她慢慢熟悉了。



有那么一回我去收房租，她早早地将一沓现金放在茶几上等我。

之前她说她手机上余额不足转不了账，就拿出来前几天刚领的现金。

我看了一眼茶几上那一沓钱，心想没啥事还专门跑一趟，就拿起现金正准备走，却被她起身拦住。

“就这么走了？”

“哦，要没事我……我就走了……”

“来都来了，正好帮我看看电脑吧！”

“啊？电脑……咋了？”

“你先坐下，先坐下……”



她一把将我扯到沙发上，从一旁的包里掏出一台笔记本电脑塞到我手里。

我接过电脑，看到她特意抹了口红，手不由地有点颤抖。

“我这电脑截图工具咋没有录屏功能呢？你帮我看看……”

说完她扭头去忙别的了。













旧版截图工具没有录屏功能？

图a06



看一下版本，是 `10.x` 的。

图a07









如果电脑上已经有 `Appx` 安装器，那么直接双击就行了。

图a04



如果双击无法运行程序安装，就用命令行吧。

打开 `PowerShell` ，输入以下命令行，回车。

```
Add-AppPackage .\Microsoft.ScreenSketch_2022.2602.49.0_neutral_~_8wekyb3d8bbwe.Msixbundle
```



出现错误，少了依赖程序。

图a01



补足依赖程序。

```
Add-AppPackage .\Microsoft.WindowsAppRuntime.1.8_8000.879.2017.0_x64__8wekyb3d8bbwe.Msix
```



再次安装后，OK。

图a02





新安装的 `截图工具` 程序所在路径：

```
C:\Program Files\WindowsApps\Microsoft.ScreenSketch_11.2602.49.0_x64__8wekyb3d8bbwe\SnippingTool\SnippingTool.exe
```



原来旧版的 `截图工具` 程序，所在路径：

```
C:\Windows\system32\SnippingTool.exe
```





按下快捷组合键：`徽标键+Shift+S` ，弹出选择提示窗口。

图a08





新版果然有录屏功能！

我刚安装好，这才发现她就坐我边上。

她故意头发搭在我肩膀上，靠得很近，把我吓一跳。

我赶紧往边上挪了挪，告诉她电脑搞好了。

结果她连看都没看电脑一眼，就问我能不能陪她吃个饭。

我这才注意到，一旁的桌子上已经摆了几个菜和两瓶酒。

嘿，我什么档次，你什么档次？

我心里想着，我可是有家有口的人，她不是知道嘛，怎么……

想到这儿我执意要走，她立马拦着我说菜都准备好了，拉着我的衣角恳请我陪她喝一杯。

我想了想，嘴里嗡嗡了一句：“今天应该没啥事，要不咱们少喝点，一会儿就走？”

她听完来了兴致，立马给酒杯里斟满了酒。

我心中暗想，看来她是有所准备啊！

果不其然，两杯酒下肚，她就跟我诉起了苦。

她说她前一阵子失恋了，这几天家里又来催，感觉活着太痛苦。

我一边忙着夹菜往嘴里送，一边安慰她，天下好男人有的是，可别往伤心处想啊！

结果她泪水一下子涌了出来，搞得我大吃一惊，嘴里的菜都掉到了桌上。

她扒桌上埋头抽泣着，细声说道，想找我这样的男人。

我赶紧把掉桌上的菜捡起来塞嘴里，咧了咧嘴说：“像我这样的可就更多了，你肯定能找到合适的”。

我刚说完，就见她抬头蹙眉，猛地端起酒杯，又是一个仰脖，不久又扒桌子上了。

我看情况不对，本想一走了之，想想不能放任不管啊，万一出点啥事可咋办？

刚想伸手去扶她，再一想吓得我自己脸都绿了！

还好我机灵，立马打电话叫来熟悉的两个女同事，将这个女租客给搀扶到里间卧室了。



自此我再也没有登门过，都是通过手机转账。

没过几个月，女租客过了合同期就不再续租了……
