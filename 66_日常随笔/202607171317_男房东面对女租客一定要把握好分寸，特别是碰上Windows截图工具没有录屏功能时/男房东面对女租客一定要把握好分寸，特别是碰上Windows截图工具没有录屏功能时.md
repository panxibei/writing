前两天漂亮女租客执意要退房，我是一点儿都没拦着。

有人说了，这年头能把房子租出去就不容易了，你咋还把租客放跑了？

说实话，我也没招，要问我怎么回事，这话得从几个月前说起……



大概在半年前吧，已经空置大半年的房子好不容易迎来了一位女租客。

你还别说，这位女租客长得年轻漂亮身材又好，估摸着30岁刚出头，一看气质就是坐办公室的白领。

她说她单身一个人，爱干净、喜欢安静，于是就租给她了。

可没成想，在接下来的日子里，这位女租客总是借各种理由找我。

像是换个电灯啊，修个马桶啊，连个网络啊……

我就认为这女租客单身一人动手能力差点，也没多想，就当上门帮个忙吧。

这一来二去，渐渐地在房子里呆的时间越来越久，我也和她慢慢熟络了。



有那么一回我去收房租，她早早地将一沓现金放在茶几上等我。

在此之前她说手机上余额不足转不了账，就拿出前几天刚领的现金让我来取。

我进门刚打了个招呼，就闻到一阵淡淡的香水味。

她端坐在沙发上，见我来了轻轻放下手机，示意我坐下。

我瞅了一眼茶几上那一沓钱，心想没啥事还专门跑一趟，就拿起现金正准备走，却被她起身拦住。



“就这么走了？”

“哦，要没事我……我就先走了……”

“也不数数？”

“这……应该不会差……”

“好几天没见你了，现在来都来了，正好帮我看看电脑吧！”

“呃……电脑……咋了？”

“你先坐下，先坐下……”



她一把将我扯到沙发上，从一旁的包里掏出一台笔记本电脑塞到我手里。

我这才注意到她换了一身清新雅致的裙子，还特意抹了淡淡的口红。

我接过电脑，手部动作不由地有点迟疑。

她冲我笑了笑：“我这电脑的截图工具怎么没有录屏功能呢？你帮我看看吧……”

说完便扭头进了厨房。



什么情况？

今天又玩的是哪出？

我满脑子问号，疑惑地打开了她的电脑……



原来，她电脑里的截图工具还真没有录屏功能。

难道我记错了？

后来我查了一下，其实就是因为旧版截图工具是不带录屏功能的。

图01



看一下版本，是 `10.x` 的。

图02



嗯，这个简单，直接安装个新版的不就结了！

新版离线安装包在文末可下载。

接着就开始安装吧！



如果电脑上已经有 `Appx` 安装器，那么直接双击就行了。

图03



如果双击无法运行程序安装也没关系，可以直接用命令行方式来安装。

打开 `PowerShell` ，切换到安装包所在文件夹路径下，然后输入以下命令行，回车。

```
Add-AppPackage .\Microsoft.ScreenSketch_2022.2602.49.0_neutral_~_8wekyb3d8bbwe.Msixbundle
```



如果出现错误，说明缺少了依赖程序，找到它安装即可。

图04



补足依赖程序，安装方法和前面讲的一样。

```
Add-AppPackage .\Microsoft.WindowsAppRuntime.1.8_8000.879.2017.0_x64__8wekyb3d8bbwe.Msix
```



再次安装后，OK。

图05



新安装的 `截图工具` 程序所在路径是这样滴。

```
C:\Program Files\WindowsApps\Microsoft.ScreenSketch_11.2602.49.0_x64__8wekyb3d8bbwe\SnippingTool\SnippingTool.exe
```



原来旧版的 `截图工具` 程序，所在路径：

```
C:\Windows\system32\SnippingTool.exe
```



你看，两个程序的文件名倒是一样，但是路径可不是一样的哦，别搞错了！

按下快捷组合键：`徽标键+Shift+S` ，弹出选择提示窗口。

图06



再来确认一下，嘿，新版果然有了录屏功能！

再看看版本，是新版 `11.x` 。

真是手到擒来啊，哈哈……嘿哟！

那位说这是怎么了？

我刚把程序安装好，猛然发觉她不知道什么时候已经坐我边上了，可把我吓得够呛，咋一点声音都没有啊！

她靠得那么近，还故意让头发搭在我肩膀上，我差点没从沙发上蹦下来……

我赶紧往边上挪了挪屁股，告诉她电脑搞好了。

结果她连看都没看电脑一眼，就问我能不能陪她吃个饭。

我这才注意到，一旁的桌子上早已摆满了饭菜外加两瓶酒。

我心里琢磨着，咱可是有家有口有老婆有孩子的人，她不是知道嘛，怎么玩什么花活……

想到这儿我执意要走，她立马拦着我说菜都准备好了，非扯住我的胳膊恳请我陪她喝一杯。

嘿，这几个意思，我什么档次，你什么档次？

我立刻义正词严地高调表明了自己的坚定立场：“那个，今天应该没啥事，要不咱们少喝点，一会儿我就走？”

她顿时来了兴致，立马给酒杯里斟满了酒。

我心中暗想，这是项庄舞剑鸿门宴还是孙二娘下蒙汗药啊！

果不其然，两杯酒下肚，她就跟我诉起了苦。

她说她前一阵子失恋了，这几天家里又来催，感觉活着太痛苦。

我一边忙着夹菜往嘴里送，一边安慰她，天底下好男人有的是，可别往伤心处想啊！

结果她泪水一下子涌了出来，这梨花带雨的把妆都给哭花了，搞得我大吃一惊，嘴里的菜都掉到了桌上。

她扒在桌上埋头抽泣，只言片语之间说是想找我这样的男人。

我赶紧把掉桌上的菜捡起来塞嘴里，借着酒劲咧嘴道：“像我这样的可就更多了，你肯定能找到合适的……”。

话刚说完，就见她举头蹙眉，猛地端起酒杯，又是一个仰脖，晃了两晃又扒桌子上了。

我看情况不对，本想一走了之，想想不能放任不管啊，万一出点啥事可咋办？

刚想伸手去扶她，又一琢磨吓得我浑身是汗，酒也醒了！

嘿，还好我机灵，立马打电话叫来两个熟悉的女同事，将这个女租客给搀扶到里间卧室了。



自此我再也没有登过门，都是通过手机转账。

再后来没过几个月，女租客过了合同期就不再续租了……
