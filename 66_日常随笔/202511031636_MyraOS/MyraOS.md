首先，为了演示方便，我们需要通过虚拟机来模拟系统的启动、运行和操作使用过程。

比如，我们使用虚拟机系统 `Qemu` ，使用起来不算太难，在 `Windows` 系统上就可以实现模拟了。

因此，我们先来安装 `Qemu` ，大家可以到官网下载安装包，也可以直接到本文文末下载。



在 `Windows` 上安装 `Qemu` ，和安装其他程序的方法没啥不一样。

图a01



安装完成后，最好添加环境变量，方便系统调用运行 `Qemu` 执行程序。

图a02



文末提供 `MyraOS` 的镜像文件下载。

下载好后，将压缩包中的 `fs.img` 和 `MyraOS.iso` 两个文件解压到某个文件夹内，比如：

```
C:\MyraOS\fs.img
C:\MyraOS\Myraos.iso
```

图a03



OK，一切准备就绪，开始尝试运行。

打开 `CMD` 命令窗口程序，或者 `Powershell` 。



窗口模式下运行：

```
qemu-system-i386 -cdrom C:\MyraOS\MyraOS.iso -drive file=C:\MyraOS\fs.img,format=raw,if=ide,index=0 -m 1024
```



全屏模式下运行：

```
qemu-system-i386 -cdrom C:\MyraOS\MyraOS.iso -drive file=C:\MyraOS\fs.img,format=raw,if=ide,index=0 -m 1024 -display gtk,zoom-to-fit=on -full-screen
```



请注意，务必要注意前面说的那两个**文件的路径**，如果你的文件夹不是 `C:\MyraOS` ，那么要修改为你当前的文件夹！
