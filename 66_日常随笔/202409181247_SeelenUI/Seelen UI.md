`Seelen UI` 的安装方法有很多种。

最简单直接的方法，就是应用商店。

> https://www.microsoft.com/store/productId/9P67C2D4T9FB?ocid=pdpshare

要是你是个专门玩电脑的，也可以利用 `Winget` 来安装。

```
winget install --id Seelen.SeelenUI
```

`Winget` 是 `Windows` 下的一款软件管理程序，我之前文章有过介绍，默认是没有这个功能的。



还有一种简单粗暴的方法，就是直接使用 `.msix` 或 `.exe` 安装包来安装。（文末有下载）

这两种都可以通过双击来安装，只不过区别是前者是有安全签名的，而后者没有，视实际需要使用吧！

如果你无法启动 `Seelen UI` 程序，双击程序啥反应都没有，那么可能是少安装了一个叫 `WebView2` 的组件。

这个 `WebView2` 的组件是用于支持 `Edge` 浏览器开发或其他功能的一套程序。

可能 `Seelen UI` 应该是用到了这个组件，但是有些系统又没有安装上，所以才会出现无法打开 `Seelen UI` 的情况。

通常 `Windows 11` 系统是带有这个组件的，如果你的系统上没有安装，没事，文末有统一下载提供。
