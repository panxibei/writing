就在昨天晚上，我看到电脑里的 `Windows` 记事本有点不一样了。

怎么个不一样呢？

你看哈，现在的 `Windows` 记事本版本是 `11.2501.31.0` 。

图01



打开应用商店，`Windows Notepad` 居然可以直接安装升级。

图02



和原来的有什么不同呢？

打开一看，难道就多出一个工具栏来？

图03



再看看，`Windows` 记事本版本的确升级为 `11.2508.38.0` 了。

其实 `Windows` 记事本更新就是增加了 `Markdown` 语法功能。

图04



在 `查看` 菜单中，多出一个 `Markdown` 的菜单项来。

下级子菜单分别为，`已编排格式` 和 `语法` 。

图05



如果你选择 `已编排格式` ，它会蹦出来说明向导。

图06



尝试写一些 `Markdown` 格式的内容看看。

可以看到，只有部分格式是被支持的，比如标题、加粗、斜体、删除线，还有列表和链接等。

但是其他格式就不被支持了，比如图片、引用还有表格等格式。

图07



查了有关资料，一些不支持的格式目前仅在预览版本的记事本程序上是可以支持的。

所以现在的版本还不支持那么全面。



你看，可以另存为 `Markdown` 了！

图08



如果想装回去，不要这个 `Markdown` 的功能，可以重新安装旧版。

安装方法，最简单的就是双击安装包，系统会自动调用 `App Installer` 来帮你安装。

如果双击不行的话，可以打开 `Powershell` ，用命令行的方式安装。

```powershell
# 基础安装命令（替换为实际文件路径）
Add-AppxPackage -Path "C:\Downloads\你的应用包.msixbundle"

# 静默安装（无弹窗，适合脚本）
Add-AppxPackage -Path "C:\Downloads\你的应用包.msixbundle" -ForceApplicationShutdown
```
