曾经失业的那段时光，成了我终身难忘的珍贵回忆。

记得有那么一次，我在外散心，不觉远行到了一座大镇甸。

街头巷尾尽显富庶繁华，到处热闹非凡，根本不像是个小地方。

我无心欣赏这一切，一大早便漫无目的地游走在街道上，冷不丁瞥见电线杆子上贴了张A4纸……



旅游景点的特色小广告升级了？

重金求子？还是娱乐返现？

我没多想，伸手就想将其撕下，却发现有点不对劲。



我立刻取下背包翻找起眼镜。

经过一番仔细端详，那纸张，用的是熟宣纸，墨迹尚新。

我又闻了闻味儿，胶水也是新刷的，想必贴了没超过67分钟。

再看那张纸上，清清楚楚地写着：

家人患病，急寻妙手回春之治愈者，重金酬谢！

我心想，这又是什么骗人的把戏？

反正无事，说不定还能遇到什么有趣之事。

环顾四周，无人注意，我迅速抄下地址，顺手将纸扯下，一边找垃圾筒，一边嚷嚷：“不乱扔垃圾，从我做起”。



按那地址，我信步来到一座庄园门前。

我心想，难道这纸上写的是真的，嘿嘿，今天的午饭有着落了。

随后园中走出一名仆人，问明来意，将我请进园中。

很快，一位老员外出现在我的面前，看上去有个50出头，却是一副饱经风霜的样子。

员外叹息一声，对我述说了前情。

原来他那唯一的儿子从小娇生惯养，前不久也不知怎么得了一种怪病。

之前也请过几个名医来看过，说是有强迫症，但却无从入手，医治无望。

现在愈发变得做事强迫，每日洗手数次，做什么都要重复重复再重复。

我点了点头，示意员外先多备些酒肉饭菜、瓜果梨桃，哦，当然还有香案纸符，方便作法。

我见员外有些犹豫，便补充说道，过会儿将人带来，我要亲自面诊。

员外这才应允，吩咐下去，便退回后院休息。



一切备齐，众人退下，不久，只见一位年轻公子背着个包来了。

他迫不及待，掏出个笔记本电脑来，一面晃着脑袋，一面质问：“你是老爷子请来的法师吗？”

我还没说啥，他又说：“你是老爷子请来的法师吗？”

一连问了四五遍。

我只得点了点头。

接着，他又将电脑打开。

电脑还未启动完毕，就见他不断地点击鼠标，很明显一副烦躁不安的样子。



我猜这会不会是强迫狂躁症？

我心里琢磨，我哪会看什么病嘛，我只是来混吃喝的啊！

等会我吃够了，见机行事我就溜吧……

那公子见我若有所思，猛地一拍我的肩膀，指着电脑说道：

“你要是能帮我搞定这个问题，我就让我爹送你100两银子！”

这突如其来的状况根本没吓倒我，我很坦然地回答道：“什……什……什么问题，你……你……你说！”



原来，他最近买了一台新电脑，却发现系统的右键菜单非常反人类，一气之下就将菜单改回原来的经典样式。

我们都知道，这 Windows 11 的右键菜单的确挺反人类的。

虽然菜单项给精简了，但是有一些选项必须得点两次、甚至两次以上才能选择。

就是这个原因，让这位公子非常不适应。

然而，当他把右键菜单改回经典样式之后，却又觉得“我用的是新系统，结果还让我用老式的右键菜单，不带这么欺负人的……”。

心理一不平衡，这强迫症就犯的一发不可收拾。

按理说有病应该去瞧瞧不是，就他这身份背景，最次也得找个正规的市级三甲。

结果这位公子愣是让老爷子出榜悬赏，这才整了开头这么一出。



“哦哦……那……那你想怎么整？”

我虽手有点抖，但心里想着，这饭菜都快凉了，还不有P快放啊！

结果这位愣是让我给出主意。

好吧，我来作个法，请神仙定夺哈！

我也顾不上那么许多了，口中念念有词，随后猛地抓过一个鸡腿就往嘴里塞。

没想到吧，头一回见这么作法的，给这位整懵了。

有门！

我一边嚼着鸡腿，一边慢条斯理地说道：

“公子请放心！”

“适才我请示上天，神佛降下旨意，令我保留新样式菜单，再追加几个常用项即可！”

我见公子不明就里，进一步解释。

意思就是，Windows 11 的反人类右键菜单咱们保持不动，只在这基础上追加想要的一些便捷的打开菜单项。

比如，常用压缩文件来打开一些文件，那就在新菜单中添加压缩文件的打开方式。

又比如，常用文本编辑程序来打开一些文本文件，那就在新菜单中添加文本编辑器的打开方式。

我话刚说完，公子猛地一拍大腿：“着啊！就是这么个意思！”

“哎哟……轻点啊，您拍的是我的大腿啊，喂！”

话音未落，公子一把按住了我的手：“接下来，就看先生的了！”



我脸上的肉抽动了两下，心里跟开了锅似的。

因为前不久，这个问题我也遇到过。

当时我在网上搜索了半天，也只找到过如何将 Windows 11 右键菜单改回经典的方法，压根就没有找到怎么在新菜单上追加菜单项的方法。

反复折腾之后，最多也只找到过经典菜单中如何修改和追加菜单项的方法。

但是这种方法对于新菜单是无效的，怎么改也只是在经典菜单中变。

这下可真的把我难住了……



我看僵持不下，于是找了个小解的借口，躲了起来。

我擦了擦汗，掏出手机，用DeepWeak搜索方法。

没成想，最后还真被我给研究出来了！

没错，我找了一个很牛艾克斯的工具：`ContextMenuCustom` 。





`ContextMenuCustom` 是一款可以编辑修改 `Windows 11` 新右键菜单的强大工具软件。

我们先来看看它怎么安装。

（安装包文末下载）



安装分两步，第一步安装证书，第二步安装程序本身。

好，我们先来安装证书。

下载并解压安装包，找到安装文件夹内的证书文件，双击安装，也就是 `.cer` 后缀名的那个文件。

接着点击 `安装证书(I)...` 。

图02



注意，一定要选择 `本地计算机(L)` 。

图03



点选 `将所有的证书都放入下列存储(P)` ，同时点击 `浏览(R)...` 按钮。

图04



选择 `受信任人` ，确定。

图05



最后点击 `完成(F)` 。

图06



证书搞定后，接下来安装 `ContextMenuCustom` ，也就是 `上下文菜单` 程序。

双击程序，即可开始安装。

图07



点击 `安装` 继续。

图08



或者如果你的电脑上没有 `应用安装程序` ，它可能不能通过双击的方式来安装，会报错，那么不用担心，我们还可以用命令行的方式来安装。

```
Add-AppxPackage [程序所在路径]\ContextMenuCustomGithubPackage_5.5.7.0_x64.msixbundle
```

好，就此我们来尝试添加一个右键菜单项吧！

点击主界面中的 `新建` 按钮，或者点击左上角的那个加号 `+` 也可以。

然后在打开的界面中，分别设置一些参数值。

比如，菜单文本写上 `用 7-Zip 打开...` ；

比如，命令写上 `"C:\Program Files\Z-Zip\7zFM.exe"` ；

比如，图标写上 `"C:\Program Files\7-Zip\7zFM.exe",0` 。

OK，经过我一番妙手回春的骚操作，公子对我是刮目相看。

也不知怎么，公子居然叹息一声，满怀惆怅，似乎泪水在眼眶中打转。

他对我坦言，其实他并没有什么大不了的病症。

之所以会有强迫症的表现，源于数月前，他听闻自己并非老员外夫妇亲生。

当时他就非常失落，却又听说，是因为他的亲生父母找了过来，好像近期就会将他接回家中。

这一系列的变故使得他心生烦躁，接下来还不知如何面对他的亲生父母。



他说着，我吃着，此时早已沟满壕平。

我呡了一口酒，说道：“我刚给你起了一卦，公子尽可宽心，老员外只有你这么一个儿子，今后家产定当全是你的，你又何必犯愁呢！”

我话音刚落，忽然一个家仆跌跌撞撞跑进屋来。

“恭……恭喜公子，贺喜公子……听老夫人说，您本家老爷给您准备了一辆柯尼赛格作为礼物，明天就将请您回去呢！”

听完这话，我轻轻放下酒杯，一把握住公子的手，语重心长地说：“恭喜公子，我那包里有我的简历……”
