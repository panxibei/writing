通常情况下，我们在运行某些程序时，系统为了安全起见，会弹出用户帐户控制窗口来向用户确认。

然而正如下图，有些系统中，用户帐户控制窗口找不着“是”，只有“否”。

图a01



正常情况下应该是这样的。

图a02



现在没得点“是”，你让我怎么运行程序呢？

这又是怎么回事呢？



我们通过计算机管理中的用户项来查看用户信息。

图a03



如果当前登录系统的用户是 `User` ，那么就查看 `User` ，双击它。

发现当前用户 `User` 隶属于 `Users` 组，也就是说它没有管理员组 `Administrators` 的权限。

图a04



因此我们就应该明白了，如果以管理员权限来运行程序时，因为没有相应的权限，所以就直接被拒绝了，因此用户帐户控制窗口就看不到“是”而只有“否”了。



但问题是，当前用户已经失去了管理员权限，再想找回权限，以普通用户的身份的确有点勉为其难啊！

怎么破？

办法总比困难多，有了，我们可以通过启动 `WinRE` 环境来解决。

啥是 `WinRE` 环境？

所谓 `WinRE` ，你可以简单地理解为 `Windows` 系统自带的系统恢复程序或功能。

当系统出现故障时，它可以派上大用场。

另外，你可能听说过还有一个 `WinPE` ，那就是单独的用于系统恢复的程序环境了。

而 `WinRE` 则是当前系统默认就有的。



好了，打开 `设置` ，`系统` > `恢复` 。

图b01



选择 `高级启动` ，选择 `立即重新启动` 。

图b02



重启过后，选择 `疑难解答` 。

图d01



接着选择 `高级选项` 。

图d02



选择 `命令提示符` 。

图d03



这时我们变个戏法，如下步骤操作，将放大镜程序 `Magnify.exe` 改成 `cmd.exe` 。

注：井号 `#` 所在行仅为注释，不必输入。

```
# 切换到你的真实的Windows系统所在盘符
C:

# 切换到 System32 目录
cd C:\Windows\System32

# 将 Magnify.exe 重命名为 Magnify.bak
ren Magnify.exe Magnify.bak

# 拷贝 cmd.exe ，同时将副本文件命名为 Magnify.exe
copy cmd.exe Magnify.exe
```

图c01



OK，关闭命令提示符窗口，继续或重启系统。

来到登录界面，点击右下角的 `辅助功能` （小人图标），点击或开启放大镜程序。

图c03



出现我们之前替换的命令提示符窗口。

在窗口中输入以下命令。

```
# 将用户 user 追加至 administrators 组中
net localgroup administrators user /add
```

图c02



命令执行完毕。

重启系统后，登录用户，再次确认，用户已经是管理员组成员了。

图b03



你可以试一下，用户帐户控制提示窗口中又可以选择“是”啦！



当然，最后别忘记把放大镜程序给换回来。

```
# 删除cmd.exe的替身文件
del Magnify.exe

# 再将备份还原回去
copy Magnify.bak Magnify.exe
```



整个这一套操作方法，同时也适用于找回因其他原因导致的用户账户或权限异常而出现的问题。
