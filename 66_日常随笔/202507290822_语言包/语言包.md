二零四五年九月三日，我国某部战区向岛国派遣的第二特别行动组出发了，我就是其中一员。

按原计划我们搭乘Y90运输机顺利登上了小笠原群岛，只见到处都插满了红旗。

作为接管岛国的首批干部，我被分配到了这个几近荒芜的地方。

初来乍到，我对这里的环境非常不适，周围弥漫着不明言状的气味，使得我内心不免陷入了慌乱。

还好有之前首批行动组的组长季东风老季，他对我的到来十分欢迎，亲自带着我熟悉起了这里的环境。



“小高啊！头一次来岛国吧？”

我立刻敬了个礼，很快又捂起了鼻子，点了点头：“季组长，很高兴在这儿见到您！”。

“哦，你不用担心！”，他冲我摆了摆手，“残留的气味是有一些，不过上周我们就已经把这里的有害物质给清理干净了，你放心大胆地在这儿工作吧！”

接着老季又郑重其事地说道：“全面接管岛国的工作可能还要持续一段时间，毕竟我们还是非常需要很多像你这样的年轻干部。”

有了季组长的这些话，我安心了许多：“季组长，您是老前辈了，有您带队我们都很放心！如果有什么工作需要，请您一定指派我去做！我一定全力以赴、不辱使命！”

“嗯，好样的！这才像祖国人民期盼的干部样子嘛！”

老季挠了挠头，压低声音道：“嘿嘿，眼下就有一个任务……”



我眼睛一亮，期盼着表现：“季组长，您说！”

“呃……是这样，我是行伍出身，年纪也大了，对这个这个电脑不是太熟悉，你帮我瞧瞧电脑……”

我一听，像泄了气的皮球：“我还以为是什么任务呢！行吧，我帮您看看！”

一听我说这话，老季眼眉一立：“怎么？屈了你的材料了？”

“实话告诉你吧，电脑其实我懂得不算少，现代战争哪能有不懂电脑的，只不过现在我们刚刚接手这里，卫星网络目前还在架设中，暂时还没打通。”

“我现在就想考考你，怎么在没网络的情况下，给安装上日语输入法……”

原来是这么回事！

后来我们回到办公室，打开电脑，我就琢磨开了……







查询当前在线操作系统中已安装或可用的功能。

```
Dism /Online /Get-Capabilities
```



语言包（含有基本输入法）。

```
Dism /Online /Add-Capability /CapabilityName:Language.Basic~~~ja-JP~0.0.1.0 /Source:C:\LanguageFeatures
```





相关语言字体。

```
Dism /Online /Add-Capability /CapabilityName:Language.Fonts.Jpan~~~und-JPAN~0.0.1.0 /Source:C:\LanguageFeatures
```



手写功能。

```
Dism /Online /Add-Capability /CapabilityName:Language.Handwriting~~~ja-JP~0.0.1.0 /Source:C:\LanguageFeatures
```



`OCR` 功能。

```
Dism /Online /Add-Capability /CapabilityName:Language.OCR~~~ja-JP~0.0.1.0 /Source:C:\LanguageFeatures
```



`Speech` 语音功能。

```
Dism /Online /Add-Capability /CapabilityName:Language.Speech~~~ja-JP~0.0.1.0 /Source:C:\LanguageFeatures
```



`TextToSpeech` 文本转语音功能。

```
Dism /Online /Add-Capability /CapabilityName:Language.TextToSpeech~~~ja-JP~0.0.1.0 /Source:C:\LanguageFeatures
```







如果是日文系统安装中文语言包和微软拼音输入法，那么将语言关键字修改成 `zh-CN` 这样。

```
Dism /Online /Add-Capability /CapabilityName:Language.Basic~~~zh-CN~0.0.1.0 /Source:C:\LanguageFeatures
```



其他的一些功能也是如此照搬。

```
# 手写
Dism /Online /Add-Capability /CapabilityName:Language.Handwriting~~~zh-CN~0.0.1.0 /Source:C:\LanguageFeatures

# OCR
Dism /Online /Add-Capability /CapabilityName:Language.OCR~~~zh-CN~0.0.1.0 /Source:C:\LanguageFeatures

# 语音
Dism /Online /Add-Capability /CapabilityName:Language.Speech~~~zh-CN~0.0.1.0 /Source:C:\LanguageFeatures

# 文本转语音
Dism /Online /Add-Capability /CapabilityName:Language.TextToSpeech~~~zh-CN~0.0.1.0 /Source:C:\LanguageFeatures
```





最后我成功地在没有联网的情况下搞定了日语输入法的安装。

老季拍了拍我的肩膀，说了一句似曾熟悉的话：“唉，你他娘的还真是个天才！”

正当我高兴的时候，老季却又给我泼了盆冷水。

“别忙哈，你要真是个天才，你把那两台电脑也给装上中文输入法！”



我顺着老季手指的方向一看，办公室前面角落里，还有两台笔记本电脑。

老季看我有些迟疑，解释道：“啊，我们接管这里，根据政策我们还是要启用当地的人员。这两台就是我们找的当地工作人员：岛国人。”

原来如此，行，接着干！



实际上和前面说的大差不差，就是把日文安装包替换为中文安装包，原理都一样。
