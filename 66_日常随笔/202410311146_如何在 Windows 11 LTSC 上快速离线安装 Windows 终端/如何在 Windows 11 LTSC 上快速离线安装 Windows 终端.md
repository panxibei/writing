如果想要离线安装呢？

在以前我曾经介绍过一种方法，就是通过应用商店的分享链接来查询并下载相应的安装包，然后再安装即可。

（离线安装包文末有下载）

图02



以管理员身份运行 `PowerShell` ，然后通过一条简单的命令即可安装。

```
Add-AppPackage .\Microsoft.WindowsTerminal_3001.21.2911.0_neutral_~_8wekyb3d8bbwe.Msixbundle
```

需要注意的是终端程序安装包的名字要确保正确。

请注意，我们现在所用的这些新系统，默认就是网络操作系统，因此像 `Windows 11` 这种比较新的系统，自然也是默认你是联网的。

所以说如果你在安装好 `Windows` 终端之类的程序后仍然打不开，那么可以尝试联下网，重新启动一下电脑，终端程序也就可以正常显示出来了。
